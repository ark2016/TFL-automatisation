# Анализ детерминированности КС-языка

**Задача:** Исследовать на детерминированность: {w₁w₂ | w₁ = u₁au₂ & w₂ = u₃au₄ & |u₁| ≤ |u₂| & |u₃| ≥ |u₄|}

> [!theorem] Вердикт: не ДКСЯ (недетерминированный) ❌
> Уверенность: 90%

## Доказательство

**Метод:** shallit

**Техника:** nerode_classes

**Мёртвый класс D конечен:** Любое слово u = v a b^r продолжается до u*a ∈ L2 (дописываем ещё одну букву a — новое последнее вхождение a оказывается в самом конце, u4'=ε ⊆ u3', условие |u3'|>=|u4'| тривиально выполнено), поэтому мёртвый класс D пуст.

**Разделяющий суффикс:** Для слова u = v a b^r будущее определяется парой чисел (|v|-r, |v|+r) (или суммой |v|+r при |v|<r): это сколько ещё b можно дописать без нового a, и сколько всего b накопится к следующему a.

**Аргумент разделения:** Два слова с разными парами (|v|-r,|v|+r) различимы: подходящий суффикс из t букв b и затем одной буквы a попадает в L2 для одного слова и не попадает для другого, так как условие |u3|>=|u4| для нового вхождения a зависит именно от этой пары. Поскольку пар (|v|-r,|v|+r) бесконечно много, а каждая пара фиксирует длину слов в своём классе — каждый класс Нероуда конечен, и таких классов бесконечно много.

**Аргумент:** L2 = {u3 a u4 | |u3| >= |u4|}. Мёртвый класс D пуст (любое слово продолжается до слова из L2 через дописывание финального 'a'). Будущее каждого слова u = v a b^r определяется парой чисел (|v|-r, |v|+r) — а значит каждый класс эквивалентности Майхилла-Нероуда содержит только слова ограниченной длины, т.е. конечен. По теореме 4.7.4 [Sh] (контрапозиция): все классы конечны ⇒ L2 не является DCFL. Это даёт non-DCFL для L2, а через допустимые для DCFL операции ∩REG (L ∩ aΣ* = a*L2) и левое частное на слово 'a' (a^{-1}(a*L2) = L2) — если бы исходный L был DCFL, то L2 тоже была бы DCFL (обе операции сохраняют DCFL) — противоречие. Значит исходный L (task u1au2_u3au4) тоже не DCFL.

**Итог рассуждения:** L = {w1w2 | w1=u1au2, |u1|<=|u2|; w2=u3au4, |u3|>=|u4|} не является DCFL. stack_strategy вернул fail: выбор разделяющего вхождения 'a' не фиксирован (нужное вхождение для условия |u1|<=|u2| или |u3|>=|u4| не является единственным и заранее известным), а после допустимого сведения L ∩ aΣ* = a·L2 сам L2 не DCFL. dcfl_pumping и closure_reduction вернули not_applicable, inh_ambiguity — not_applicable. Агент shallit доказал non_dcfl для L2 = {u3au4 | |u3|>=|u4|} по теореме 4.7.4 [Sh] (все классы Нероуда конечны, мёртвый класс пуст), а затем свёл исходный язык к L2 через два сохраняющих DCFL сведения: пересечение с регулярным aΣ* (L ∩ aΣ* = a·L2) и левое частное на слово 'a' — если бы L был DCFL, то и L2 был бы DCFL, противоречие. Confidence=0.9.

**Основной источник:** shallit
