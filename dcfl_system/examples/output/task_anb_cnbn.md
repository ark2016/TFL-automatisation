# Анализ детерминированности КС-языка

**Задача:** Является ли данный язык детерминированным? {aⁿb*(cⁿ|bⁿ)ac* | n > 0}

> [!theorem] Вердикт: не ДКСЯ (недетерминированный) ❌
> Уверенность: 92%

## Доказательство

**Метод:** shallit

**Бесконечное множество:** M = {a^n b^n | n >= 1} — бесконечное множество строк над {a,b,c}.

**Разделяющий контекст:** Для элемента u = a^p b^p разделяющий суффикс: w = c^p a.

**Два элемента:** u = a^p b^p и v = a^q b^q, где p ≠ q — два произвольных различных элемента M.

**Аргумент:** u·w = a^p b^p c^p a принадлежит L (ветвь cⁿ: n=p, k=p, m=0). v·w = a^q b^q c^p a НЕ принадлежит L: для ветви cⁿ нужно c^q, но суффикс содержит c^p (p≠q); для ветви bⁿ строка должна иметь вид a^q b^j a c^m, но символы c стоят перед a, что не соответствует формату. Таким образом, любые два различных элемента M разделимы, бесконечного однородного подмножества не существует, и по лемме Шэллита L не является DCFL.

**Итог рассуждения:** Язык L = {aⁿ b* (cⁿ|bⁿ) a c* | n > 0} не является детерминированным контекстно-свободным (не DCFL). Это доказано с помощью леммы Шэллита.

Доказательство (агент shallit, верифицирован оракулом):
1. Определяем бесконечное множество M = {aⁿbⁿ | n ≥ 1}.
2. Берём два произвольных различных элемента u = aᵖbᵖ и v = aᵍbᵍ из M, где p ≠ q.
3. Разделяющий суффикс: w = cᵖa.
4. Конкатенация u·w = aᵖbᵖcᵖa принадлежит L (ветвь cⁿ: n=p, b*=bᵖ, cⁿ=cᵖ, a, c*=ε).
5. Конкатенация v·w = aᵍbᵍcᵖa НЕ принадлежит L: для ветви cⁿ необходимо cᵍ, но суффикс содержит cᵖ (p≠q); для ветви bⁿ строка должна иметь вид aᵍbʲac^m, но символы c стоят перед a, что не соответствует формату.
6. Таким образом, любые два различных элемента M разделимы соответствующим суффиксом, бесконечного однородного подмножества не существует.
7. По контрапозиции леммы Шэллита, L не является DCFL.

Дополнительно, агент stack_strategy независимо пришёл к выводу о невозможности построения DPDA: две ветви языка требуют взаимоисключающих стратегий работы со стеком при чтении символа 'b' после блока aⁿ (сохранять стек для ветви cⁿ или расходовать для ветви bⁿ), что невозможно реализовать детерминированно. Агент closure_reduction также подтвердил направление non_dcfl, хотя его доказательство было неполным. Оракул верифицировал доказательство Шэллита (3/3 проверок пройдено).
