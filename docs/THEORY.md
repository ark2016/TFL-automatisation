## 1. DCFL

Здесь DCFL означает языки ДМПА с **принятием по заключительному состоянию после чтения всего
слова**, с разрешёнными ε-переходами. Принятие по пустому стеку без концевого маркера задаёт
более узкий класс: такой детерминированный язык префиксно-свободен. Технический концевой маркер
не является буквой исходного слова; его введение и удаление требуют соответствующей конструкции.
Алфавиты конечны; для теоремы о бесконечном классе Нероуда дополнительно требуется Σ ≠ ∅.

### 1.1. Лемма о накачке для DCFL (двухсловная, [Yu]) — **[проверено]**

**Лемма.** Пусть L — DCFL. Существует константа p такая, что для любых двух слов
xy ∈ L и xz ∈ L с |x| > p и одинаковыми первыми буквами у y и z (⁽¹⁾y = ⁽¹⁾z, оба непусты)
выполнено хотя бы одно из условий:

- **(1) — накачка внутри префикса.** x = x₁x₂x₃x₄x₅, |x₂x₄| ≥ 1, |x₂x₃x₄| ≤ p, и для всех i ≥ 0
  x₁x₂ⁱx₃x₄ⁱx₅·y ∈ L **и** x₁x₂ⁱx₃x₄ⁱx₅·z ∈ L.
  Пара (x₂, x₄) может стоять **в любом месте** x; ограничена только длина окна x₂x₃x₄.
- **(2) — синхронная накачка с суффиксами.** x = x₁x₂x₃, y = y₁y₂y₃, z = z₁z₂z₃,
  |x₂| ≥ 1, |x₂x₃| ≤ p (x₂ лежит в последних p символах x), и для всех i ≥ 0
  x₁x₂ⁱx₃·y₁y₂ⁱy₃ ∈ L **и** x₁x₂ⁱx₃·z₁z₂ⁱz₃ ∈ L.

Отрицание (доказательство L ∉ DCFL): для всякого p указать xy, xz ∈ L, |x| > p, ⁽¹⁾y = ⁽¹⁾z,
и показать, что **и (1), и (2) нарушены** — для каждого допустимого разбиения найти i, при котором
хотя бы одно из двух накачанных слов выходит из L.

Замечания.
- Условие ⁽¹⁾y = ⁽¹⁾z сохраняется в рабочем контракте. В проверенной формулировке
  [Ya, Lemma 3.2] оно не требуется; добавление условия лишь ограничивает выбор свидетелей
  отрицания. Полный текст оригинала [Yu] в этой ревизии не проверялся.
- В [Ya, Lemma 3.2, версия v3] граница 2^{6n⁶} относится к n состояниям ДМПА в указанной там
  нормальной форме (ideal shape); для задач достаточно «существует p».

**[ошибка]** В `dcfl_system/prompts/dcfl_pumping.md`, `tz_dcfl_agent_system.md` §5.4 и в разборе
[Курс] `Практика/экзамен/2025_22.md` условие (1) записано как **одиночный** фактор x₂ в последних p
символах x. Такая «лемма» ложна: она отвергает DCFL {aⁿbⁿcᵐ}. Контрпример-ловушка:
x = aⁿbⁿ, y = c, z = cc. Одиночная накачка bʲ и синхронная накачка bʲ ~ cʲ ломают оба слова, но
настоящее условие (1) выполняется парой (x₂, x₄) = (a, b) на границе блоков:
a^{n-1}·aⁱ·bⁱ·b^{n-1}·c ∈ L. В [Курс] 2025_22 префикс x = aⁿ унарен,
однако там есть отдельная ошибка в исключении условия (2), разобранная ниже.

**Пример (для промпта).** L = {aⁿbⁿ | n ≥ 1} ∪ {aⁿb²ⁿ | n ≥ 1} ∉ DCFL.
Возьмём n > p + 1, x = aⁿbⁿ⁻¹, y = b, z = bⁿ⁺¹ (оба начинаются с b; xy = aⁿbⁿ, xz = aⁿb²ⁿ ∈ L).
- (1): пара (x₂, x₄) с окном ≤ p. Если один из накачиваемых факторов содержит и a, и b,
  его удвоение создаёт ba, поэтому результат не лежит даже в a*b*. Иначе оба фактора однородны.
  Обе части в a-блоке: при i = 2 получаем a^{n+|x₂x₄|}bⁿ ∉ L.
  Обе в b-блоке: aⁿb^{n+|x₂x₄|} ∉ L (так как |x₂x₄| ≤ p < n). Пара на границе, x₂ = aˢ, x₄ = bᵗ
  (s + t ≥ 1): из a^{n+s}b^{n+t} ∈ L следует t = s; тогда из a^{n+s}b^{2n+t} ∈ L следует t = 2s,
  т.е. s = t = 0 — противоречие.
- (2): x₂ лежит в последних p символах x, т.е. x₂ = bˢ, s ≥ 1; y₂ ∈ {ε, b}. При i = 2 первое слово
  равно aⁿb^{n+s+|y₂|} с 1 ≤ s + |y₂| ≤ p + 1 < n, т.е. не лежит в L.
Оба условия нарушены ⇒ L ∉ DCFL. ∎
(Ни дополнение, ни ∩REG здесь не помогают: L̄ ∩ a*b* = {aⁿbᵐ | m ≠ n, m ≠ 2n} — КС.)

**Исправление примера из курса (2025_22).** Язык
S = {aⁱbʲcᵏ | i ≤ j ∨ j = k; i,j,k ≥ 1} действительно не DCFL, но предложенные
w = aⁿbⁿcⁿ⁺¹, w′ = aⁿbⁿ⁺¹cⁿ⁺¹, x = aⁿ **не опровергают лемму Ю**.
При n ≥ 2 условие (2) выполнено: x₂ = a, y₂ = b, z₂ = ε; первая накачанная строка
всегда имеет i = j, вторая — j = k. Это допустимо при p ≥ 1 для всех показателей накачки.

Корректное доказательство использует MIN из §1.4:
MIN(S) ∩ a⁺b⁺c²c* = {aⁱbʲcʲ | i > j ≥ 2} = K.
Если i ≤ j, первый принятый префикс заканчивается уже первым c; если i > j, он заканчивается
ровно j-м c. Язык K не КС: при константе накачки p ≥ 2 берём a^{p+1}bᵖcᵖ.
Окно длины ≤ p не затрагивает одновременно a- и c-блоки. Фактор, пересекающий границу блоков,
при удвоении нарушает порядок a*b*c*. Для однородных факторов обозначим суммарные приращения
чисел a,b,c через A,B,C. Если B ≠ C, удвоение нарушает b = c. Если B = C > 0,
то A = 0 и удвоение даёт j ≥ i. Если B = C = 0, то A > 0 и удаление даёт i ≤ j.
Все разбиения исключены, следовательно K не КС, а S не DCFL. Это самостоятельное доказательство,
не результат конечного перебора.

### 1.2. Теорема Шаллита (классы Майхилла–Нероуда) — **[проверено]**

**Теорема 4.7.4 [Sh].** Для конечного непустого алфавита Σ, если L ⊆ Σ* — DCFL, то хотя бы один класс эквивалентности
Майхилла–Нероуда языка L (x ~_L y ⇔ ∀z: xz ∈ L ⇔ yz ∈ L) **бесконечен**.

*Набросок доказательства [Sh].* Возьмём ДМПА для L, читающий всё входное слово (Lemma 4.7.1).
В конечное управление включим флаг принятия на текущей границе входа (для ε-переходов).
Для каждого x выберем продолжение x′, после которого высота стека минимальна среди всех
продолжений x; конфигурация (q, Aα). Ни одно дальнейшее продолжение не опускает стек ниже A,
поэтому поведение на любом z зависит только от (q, A). Пар (q, A) конечное число, а слов xx′
бесконечно много ⇒ бесконечно много слов с одинаковым множеством расширений. ∎

**Контрапозиция (рабочая форма).** Если **все** классы Нероуда языка L конечны, то L ∉ DCFL.
Стандартный способ: показать, что любые два различных слова u ≠ v различимы (∃w: ровно одно
из uw, vw лежит в L) — тогда все классы одноэлементны.

**Следствие [Sh].** PAL = {x ∈ {a,b}* | x = xᴿ} ∉ DCFL; аналогично {wwᴿ}.
Разделяющий суффикс для u ≠ v: w = b·a^N·b·uᴿ с N = 2|uv| (для {wwᴿ} чётность обеспечена).
uw — палиндром; vw — нет: aᴺ — единственная максимальная серия a, поскольку N > |u|, |v|.
В палиндроме эта серия обязана отразиться в себя, а оставшиеся части v·b и b·uᴿ тогда дают v = u.
При u ≠ v имеем N ≥ 2; для чётных палиндромов |uw| = 2|u| + N + 2 чётно.

**Ограничение метода — «мёртвый» класс.** D = {x | ∄z: xz ∈ L} — тоже класс Нероуда. Если D
бесконечен (например, L ⊆ a*b*: все слова вне Pref(a*b*) мертвы), теорема выполняется автоматически
и **ничего не даёт**. Поэтому перед применением нужно проверить, что D конечен, а это значит D = ∅:
D замкнут относительно продолжений справа (x ∈ D ⇒ xΣ* ⊆ D), так что непустой D бесконечен. D = ∅ означает, что
каждое слово продолжается до слова из L (как у PAL). Агент обязан явно это обосновать; иначе — `not_applicable`.

Конечный поиск продолжений не устанавливает x ∈ D. Например, в регулярном языке {aⁿ | n ≥ 20} над {a}
мёртвых слов нет, но для ε недостаточно перебора продолжений длины ≤ 6. Ответ «продолжение не найдено»
остаётся неизвестностью, пока нет полного алгоритма проверки Pref(L) или доказанной достаточной границы.

**[ошибка]** Старая формулировка в `shallit.md`/`tz_dcfl` §5.5: «если L ∈ DCFL, то для всякого
бесконечного M ⊆ Σ* найдётся бесконечное однородное M′ ⊆ M». Ложна: для DCFL {aⁿbⁿ} и M = {aⁿ}
любые два элемента различимы суффиксом bᵏ. Совет «постройте M, в котором любые два элемента
различимы» — та же ошибка: одного бесконечного семейства недостаточно, нужны **все** классы.

### 1.3. Детерминизм и префиксы (лемма о продолжении) — **[проверено]**

Ключевое наблюдение [Sh, слайд IV 40]: для ДМПА вычисление на xy начинается с вычисления на x,
поэтому принятие x и принятие xy «согласованы» (у НМПА принимающие вычисления на x и xy могут
быть разными).

**Лемма.** Пусть L — DCFL, $ ∉ Σ. Тогда
- (a) haspref(L) = {xy | x ∈ L, xy ∈ L, y ≠ ε} — DCFL;
- (b) L_$ = {x$y | x ∈ L, xy ∈ L} — DCFL.

*Доказательство (b).* ДМПА M для L нормализуем (читает всё слово, без бесконечных ε-циклов).
M′ моделирует M и хранит флаг F «после последней буквы Σ, включая последующие ε-переходы,
посещено заключительное состояние» (как в Thm 4.7.2 [Sh]); до первой буквы учитывается принятие ε.
На $ выполняются все вынужденные ε-переходы M, затем проверяется F (x ∈ L).
Сам $ не меняет конфигурацию M и **не сбрасывает F**: при y = ε слово x$ должно приниматься.
F сбрасывается только при чтении следующей буквы Σ, после чего снова учитываются заключительные
состояния. Дополнительное конечное управление требует ровно один $; в конце принимается состояние
с уже прочитанным $ и F = 1. Переход по $ добавляется только там, где нет вынужденного ε-перехода,
так что детерминизм сохраняется. Для (a) хранится также P: перед чтением каждой следующей буквы Σ
выполняется P := P ∨ F. Тогда P отмечает именно **собственный** принятый префикс, а не текущее слово;
принятие определяется F ∧ P. В частности, haspref(L) не содержит ε, а ε ∈ L учитывается как
собственный префикс каждого непустого слова L. ∎

**Применение.** L_$ ∩ R ∉ CFL (для регулярного R) ⇒ L ∉ DCFL (DCFL замкнуты относительно ∩REG и
лежат в CFL). Примеры:
- L = {aⁿbⁿ} ∪ {aⁿb²ⁿ}: L_$ ∩ a*b*$b⁺ = {aⁿbⁿ$bⁿ} ∉ CFL ⇒ L ∉ DCFL.
  (haspref(L) = {aⁿb²ⁿ} — DCFL, здесь нужен именно маркер.)
- L = {aⁿbⁿ} ∪ {aⁿbᵐcⁿ}, n,m ≥ 1 [Sh, IV 40]: haspref(L) = {aⁿbᵐcⁿ | m ≥ n} ∉ CFL ⇒ L ∉ DCFL.

### 1.4. Замкнутость DCFL — **[источники и границы указаны отдельно]**

Замкнуты: дополнение относительно фиксированного Σ*, ∩ REG, обратный гомоморфизм
(включая стирающий); правое частное L/R = {x | ∃y ∈ R: xy ∈ L} при регулярном R;
MIN(L) = {x ∈ L | ни один собственный префикс x не лежит в L};
MAX(L) = {x ∈ L | ни одно собственное продолжение x не лежит в L};
обратное отображение **детерминированного последовательного** GSM, в том числе со стирающим
выходом; haspref и L_$ (п. 1.3). Для недетерминированного многозначного трансдьюсера это
утверждение об обратном образе не переносится: выбор между выходами 0w и 1w сводит обратный
образ DCFL 0{aⁿbⁿ} ∪ 1{aⁿb²ⁿ} к не-DCFL {aⁿbⁿ} ∪ {aⁿb²ⁿ}.

Таблица [Sh, IV 30] подтверждает дополнение, обратный гомоморфизм и отрицательные замыкания;
∩ REG следует из произведения ДМПА и ДКА. MIN получается тем же флагом собственного принятого
префикса, что в §1.3, с условием F ∧ ¬P. Для обратного GSM конечное управление хранит его состояние
и непрочитанный остаток выходного блока, моделируя ДМПА детерминированно; при пустом выходе
сохраняется текущий флаг принятия. Правое регулярное частное использует регулярность множества
конфигураций ДМПА, из которых существует принимающее продолжение из R: произведение с ДКА для R
и конечные сводки операций над стеком дают регулярный тест стека, который поддерживается аннотациями
стековых символов. Тот же тест для R = Σ⁺ вместе с текущим флагом принятия даёт MAX.
Это не применение замкнутости под разностью двух DCFL — такой замкнутости нет.
Оригинал [GG] пока не прочитан целиком; его атрибуция не означает проверки исходного доказательства.

Почему тест конфигурации регулярен: в произведении с ДКА для R конечна таблица Pop(p,A,q),
означающая существование пути, который снимает A и всё временно положенное над ним, не читая
остаток стека; конечна и таблица Acc(p,A), означающая достижение принятия до снятия A.
Существование принимающего продолжения распознаёт НКА, читающий исходный стек сверху вниз:
он применяет Pop к последовательным символам либо, встретив Acc, переходит в принимающий
режим, игнорирующий остаток. Дно обрабатывается отдельным символом. Разбиение любого успешного
пути по первым снятиям исходных ячеек даёт полноту этого НКА; склейка таких путей — корректность.
Конечное отношение переходов НКА на каждом суффиксе стека хранится в аннотации ячейки;
push пересчитывает его, pop восстанавливает сохранённое. Поэтому исходный ДМПА может
детерминированно поддерживать этот тест без второго стека. Для MAX ДКА отслеживает условие y ≠ ε.

Левое частное на **фиксированное слово** также сохраняет DCFL (старт из достигнутой фиксированной
конфигурации). Левое частное на произвольный регулярный язык в общем случае не сохраняет DCFL:
для H = 0{aⁿbⁿ} ∪ 1{aⁿb²ⁿ} частное {0,1}⁻¹H равно не-DCFL {aⁿbⁿ} ∪ {aⁿb²ⁿ}.
Не замкнуты: ∪, ∩ (DCFL ∩ DCFL), конкатенация, звезда, обращение, гомоморфизм
(в т.ч. ε-свободный).

### 1.5. Существенная неоднозначность — **[проверено]**

Существенно неоднозначный ⇒ не UnambCF ⇒ не DCFL (у DCFL есть LR(1)-грамматика, LR(k)-грамматики
однозначны). Пример [Sh, Thm 4.4.1]: {aⁱbʲcᵏ | i = j ∨ j = k}.
Неоднозначность **грамматики** не говорит ничего о языке (Format 2).

## 2.0. Кванторы накачки и определение КС-языка

У КС-языка существует p ≥ 1 такое, что **для каждого** z ∈ L, |z| ≥ p, **существует** допустимое
разбиение z=uvwxy, |vwx| ≤ p, |vx| ≥ 1, с uvⁱwxⁱy ∈ L **для всех** i ≥ 0 [R-Pump, с. 7].
Не-КС доказательство должно отрицать именно этот порядок: ∀p ∃z ∀разбиение ∃i с выходом из L.
Для Огдена длина заменяется числом отмеченных позиций [Sh, Lemma 4.3.1].

Конечная проверка p=3,4 и i=0,2,3 — диагностика. Даже полное закрытие разбиений при этих p не доказывает
общую теорему: у L={a¹⁰} оно выполняется, но константа p=11 удовлетворяет лемме вакуумно. И наоборот,
выживание разбиения при трёх i не доказывает выживания при всех i. Нужное i может зависеть от p и разбиения.
`None` оракула означает неизвестность, а не непринадлежность. Эти ограничения одинаковы для леммы Ю.

Если весь исходный язык **задан корректной КС-грамматикой**, его контекстная свобода следует из определения
[R-Pump, `cfl`; R-CFL, с. 3–4]. Поиск другой грамматики и выборочное сравнение не требуются. Это не относится
к подмножеству L(G), заданному дополнительным фильтром, и не устанавливает DCFL или LL(k).

**Пример Огдена для промпта.** L={aⁱbʲcᵏdˡ | i=0 или j=k=l}, показатели неотрицательны,
удовлетворяет обычному условию накачки с p=1: при i>0 накачиваем одну начальную a
(удаление последней a переводит в ветвь i=0), а при i=0 — любую букву непустого слова.
Тем не менее L не КС. Для Огдена берём z=abᵖcᵖdᵖ, отмечаем все b, используем i=2.
Хотя окно vwx может пересечь все блоки, vx обязано содержать b. Если v или x пересекает
границу разных букв, удвоение нарушает порядок a*b*c*d*. Иначе каждый из двух факторов
однороден; один содержит b, поэтому хотя бы один из c/d-блоков не меняется. Число b растёт,
эта неизменная длина остаётся p, число a положительно — слово выходит из L.

## 2. CFL: ложный эталонный пример — **[проверено перебором]**

Задача: L = {w₁w₂w₁w₃ | w₁ ∈ {a,b}⁺, w₂ ∈ {b,c}⁺, w₃ ∈ {a,c}⁺}.

**[ошибка]** В пяти местах (`cfl_closure_reduction.md`, `cfl_pumping.md` Example 2,
`cfl_reasoning.md`, `cfl_retry_planner.md`, `tz_cfl_agent_system.md` §closure) утверждается
L ∩ a⁺b⁺a⁺c⁺ = {aⁿbᵐaⁿcᵏ}. На самом деле
L ∩ a⁺b⁺a⁺c⁺ = {aⁿbᵐaʲcᵏ | j ≥ n} — **это КС-язык** (лишние a уходят в w₃ ∈ {a,c}⁺):
abaac ∈ L (w₁ = a, w₂ = b, w₃ = aac). Слово aᵖbaᵖc накачивается вверх во втором блоке, оставаясь
в L. Вариант в tz (R = a*(b|c)*a*(a|c)*) ложен по той же причине.

**Исправленный пример.** R = a⁺b⁺ac·a⁺b⁺ac (регулярный).
L ∩ R = {aⁿbᵐac·aⁿbᵐac | n, m ≥ 1}.
*Почему.* w₁ — префикс из {a,b}⁺: варианты aⁱ (i < n₁) — тогда w₂ начинается с a, нельзя;
aⁱ¹ — тогда w₂ = bʲ¹, второй w₁ = aⁱ¹ должен начаться с символа a после b-блока, но там стоит
«a c a…» ⇒ i₁ = 1 и w₃ содержит b — нельзя; aⁱ¹bʲ (j ≤ j₁) — второй экземпляр должен начаться
на «a c», нельзя; остаётся w₁ = aⁿbᵐa, w₂ = c, второй w₁ = aⁿbᵐa ⇒ n₂ = n, m₂ = m, w₃ = c.
Проверено перебором для 1 ≤ n₁,m₁,n₂,m₂ ≤ 4.

*L ∩ R ∉ CFL.* Пусть p — длина накачки, z = aᵖbᵖac·aᵖbᵖac ∈ L ∩ R, |z| = 4p + 4.
Для любого z = uvwxy, |vwx| ≤ p, |vx| ≥ 1, слово uwy (i = 0) ∉ L ∩ R:
- если vx содержит c или одиночный разделитель a — uwy ∉ R (в R ровно два блока «ac»);
- иначе vx состоит из букв не более чем одного a-блока и одного b-блока (|vwx| ≤ p не дотягивает
  до одноимённого блока второй половины); если блок опустошён — uwy ∉ R, иначе счётчики n₁ ≠ n₂
  или m₁ ≠ m₂ — uwy ∉ L ∩ R.
Единый выбор i = 0 для всех разбиений; проверено перебором всех 233 разбиений при p = 3.
Поскольку CFL ∩ REG ⊆ CFL, L ∉ CFL. ∎

Для `cfl_pumping.md` (Example 2): прямая накачка L ненадёжна — накачанное слово может
переразложиться (w₃ поглощает лишние a). Правильное поведение агента pumping_cfl на этой задаче —
`uncertain` с рекомендацией closure_reduction (R выше), либо накачка уже суженного языка L ∩ R,
если он передан как hint.

## 3. LL(k)

### 3.1. LL(k)-грамматика vs strong LL(k) — **[проверено]**

Здесь k ≥ 1, грамматика конечна, ε не является буквой алфавита. LL(k)-**язык** — язык,
имеющий хотя бы одну LL(k)-грамматику; отрицательный тест данной грамматики не решает этот вопрос.
Определения сверены по [Ni, Definitions 8.7–8.8, с. 109–110 / PDF-с. 116–117]; полный текст [AU]
не прочитан. Ниже приведено самостоятельное обоснование конечного алгоритма, а не ссылка на
непроверенную формулу из [AU].

Определения. G — **LL(k)**, если в любых двух левых выводах S ⇒* wAα ⇒ wβα ⇒* wx и
S ⇒* wAα ⇒ wγα ⇒* wy с FIRST_k(x) = FIRST_k(y) выполнено β = γ.
G — **strong LL(k)** (SLL(k)), если для любых различных правил A → β, A → γ
FIRST_k(β·FOLLOW_k(A)) ∩ FIRST_k(γ·FOLLOW_k(A)) = ∅ (глобальный FOLLOW_k).

Факты.
- SLL(k) ⇒ LL(k) (грамматика). При k = 1 классы грамматик совпадают; при k ≥ 2 — нет.
- **[Ni, Theorem 10.4, с. 140–141 / PDF-с. 147–148; со ссылкой на RS]** Для каждой LL(k)-грамматики существует структурно эквивалентная strong-LL(k)-грамматика
  того же языка ⇒ **классы языков совпадают**: LL(k)-языки = SLL(k)-языки. Различие только на уровне
  грамматик (Format 3).
- Пример, проверенный непосредственно: S → aAaa | bAba, A → b | ε — LL(2), но не SLL(2): FOLLOW₂(A) = {aa, ba},
  правила A → b и A → ε конфликтуют на ba; при локальном follow {aa} и {ba} конфликта нет.
  SLL-тест впервые проходит при k = 3.

**[ошибка]** `ll_system/lib/ll_table_builder.py` + `first_follow.py` решают SLL(k) (director set через
глобальный FOLLOW_k), а вердикт формулируется как «не LL(k)» с confidence 1.0.

**Полный LL(k)-тест (из определения; аннотации как в [Ni, Theorem 10.4]).** Для нетерминала A множество локальных
follow-множеств σ(A) = {FIRST_k(α) | S ⇒*_lm wAα} вычисляется итеративно:
σ(S) ∋ {ε}; для каждого правила A → X₁…Xₙ, каждого L ∈ σ(A) и каждого нетерминала Xᵢ
добавить FIRST_k(X_{i+1}…Xₙ) ⊕_k L в σ(Xᵢ), но только если предшествующие символы
X₁…X_{i−1} могут вывести терминальное слово: иначе Xᵢ не достигается после терминального
префикса в левостороннем выводе. Итерировать до неподвижной точки (множества конечны: ⊆ Σ^{≤k}).
G — LL(k) ⇔ для всех A, всех L ∈ σ(A) и всех пар различных правил A → β, A → γ:
(FIRST_k(β) ⊕_k L) ∩ (FIRST_k(γ) ⊕_k L) = ∅.
*Обоснование.* Любая добавленная пара (Xᵢ,L′) реализуется левым выводом: применяем правило
к достижимому A, затем выводим терминальные слова из предшествующих символов. Обратно, каждый
достижимый левый контекст возникает таким шагом из контекста родителя. Индукция по длине вывода
даёт точность неподвижной точки. Равенство FIRST_k(βα) = FIRST_k(β) ⊕_k FIRST_k(α)
превращает определение LL(k) ровно в выписанный тест. Следовательно, при фиксированном k вопрос
для данной грамматики разрешим. Аннотирование A его конкретным L разделяет контексты:
все вхождения (A,L) имеют одно локальное follow-множество, поэтому LL(k)-условие исходной грамматики
становится strong-условием аннотированной; стирание аннотаций сохраняет язык и деревья выводов.
При k=1 конфликт глобальных director-множеств уже реализуется в одном контексте: либо обе
альтернативы дают одну первую букву, либо одна nullable и эта буква входит в соответствующий
follow; если nullable обе, годится любой продуктивный контекст. Это объясняет LL(1)=SLL(1).
Число таблиц в худшем случае экспоненциально — нужен бюджет (лимит таблиц/времени ⇒ `unknown`).
Порядок: сначала SLL-тест (дёшево; прошёл ⇒ LL(k)); не прошёл при k ≥ 2 ⇒ полный тест.
FIRST/FOLLOW и локальные σ вычисляются до настоящей неподвижной точки; исчерпание вычислительного
лимита не считается сходимостью. FIRST_k(α) учитывает только префиксы **терминально выводимых** слов:
если суффикс α непродуктивен, результат пуст даже при уже набранных k терминалах.
Минимальность найденного k установлена только после определённого отрицательного результата для
каждого меньшего k. `unknown` на меньшем значении нельзя перезаписывать более поздним успехом как «min k».
В коде глобальный FOLLOW дополняется новым символом `$` до k позиций, локальный использует ε.
Эти соглашения эквивалентны по совпадению lookahead, поскольку `$` запрещён в исходном алфавите.

**Сертификаты «не LL(k) ни для какого k» для грамматики** (после удаления бесполезных символов):
левая рекурсия A ⇒⁺ Aα [AU]; неоднозначность (два дерева вывода одного слова). Без сертификата
результат перебора k ≤ K формулируется как «не LL(k) при k ≤ K», не conclusive.

### 3.2. Свойства класса LL-языков — **[проверено]**

- REG ⊊ LL(1) (языки): грамматика ДКА Q → aδ(Q,a), Q → ε для допускающих состояний — LL(1),
  а {aⁿbⁿ} — нерегулярный LL(1)-язык. LL(k) ⊊ LL(k+1) как языки: утверждение сверено в
  [Ni, с. 109], доказательство строгой иерархии в [Kurki-Suonio 1969; RS] в этой ревизии не прочитано.
  ⋃_k LL(k) ⊊ DCFL = LR(1); собственность первого включения также следует из примеров ниже.
- Всякая LL(k)-грамматика — LR(k) и однозначна.
- **Не замкнуты относительно ∪**: {aⁿbⁿ} и {aⁿcⁿ} — LL(1), их объединение — не LL(k) ни при каком k (п. 3.3).
- **Не замкнуты относительно ∩ REG.** **[ошибка]** `ll_system/CLAUDE.md`: «LL ∩ REG = LL».
  Контрпример: L = {aⁿw | w ∈ {b,c}ⁿ, n ≥ 0} — LL(1) (S → aSX | ε, X → b | c; director(S→aSX) = {a},
  director(S→ε) = {b, c, $}), R = a*b* ∪ a*c* регулярен, L ∩ R = {aⁿbⁿ} ∪ {aⁿcⁿ} — не LL.
- Замкнутость относительно дополнения/конкатенации без источника не утверждать.

### 3.3. Как доказывать «не LL(k) ни для какого k» — **[проверено]**

**(A) Не DCFL ⇒ не LL.** Все техники раздела 1 (лемма Ю, теорема 4.7.4, дополнение, L_$).
Так доказывается не-LL для PAL, {wwᴿ}, {aⁱbʲcᵏ | i=j ∨ j=k} и т.п.

**(B) Существенная неоднозначность ⇒ не LL** (LL-грамматики однозначны).

**(C) Аргумент «развилки» (left-part property) — для DCFL, не являющихся LL.**
*Свойство общего вывода — локальное доказательство.* Пусть G — LL(k), два различных слова
из L(G) имеют наибольший общий префикс длины ℓ ≥ k (одно может быть префиксом другого).
Их левые выводы совпадают, пока максимальный терминальный префикс текущей формы имеет длину
≤ ℓ−k: оставшиеся k букв одинаковы, поэтому определение LL(k) вынуждает выбрать одно правило.
На первом шаге, после которого эта длина превышает ℓ−k, получаем общую форму wδ с
ℓ−k < |w| ≤ ℓ: w — префикс обоих слов. Шаг существует, поскольку оба конечных вывода
порождают слова длины не меньше ℓ. Условия на lookahead хвостов после всего общего префикса нет.
**Исправлено:** прежняя оценка |x|−k < |w| ≤ |x|+k для произвольного выбранного x ложна:
S → a¹⁰⁰A, A → b | c, k=1, x=a даёт скачок терминального префикса от 0 сразу к 100.
Поскольку грамматика контекстно-свободна, поддеревья символов
δ = X₁…X_m независимы: **любая смесь** (для каждого Xᵢ берём его вывод из первого или из второго
слова) даёт слово из L(G).

*Шаблон доказательства для L = {aⁿbⁿ} ∪ {aⁿcⁿ} (n ≥ 1).* Пусть G — LL(k)-грамматика для L, n > k.
Слова aⁿbⁿ и aⁿcⁿ имеют общий префикс aⁿ (лишь lookahead после a^{n−k} различается), поэтому есть
общая форма aʲδ, n − k < j ≤ n, с δ ⇒* a^{n−j}bⁿ и δ ⇒* a^{n−j}cⁿ. Пусть δ = X₁…X_m с выводами
y₁…y_m и z₁…z_m. Если yᵢ содержит b, а zⱼ содержит c при i≠j, независимая смесь этих двух
поддеревьев содержит обе буквы и не лежит в L. Значит все b и c сосредоточены в одном индексе t*:
X_{t*} ⇒* aˢbⁿ, X_{t*} ⇒* a^{s′}cⁿ, s,s′ ≤ k−1. Это нетерминал, поскольку терминал не меняется
между выводами. Остальные Xᵢ дают слова из a*; замена одного такого слова при сохранении bⁿ
обязана сохранить число a, поэтому yᵢ=zᵢ; отсюда также s=s′. Нетерминалов конечное число и
0 ≤ s ≤ k−1, поэтому найдутся n ≠ n′
с одинаковой парой (X_{t*}, s). Подставив в вывод aⁿbⁿ вывод X_{t*} ⇒* aˢb^{n′}, получаем
aⁿb^{n′} ∈ L(G) = L — противоречие. ∎

*Второй пример:* {aⁿ0bⁿ} ∪ {aⁿ1b²ⁿ} — DCFL, не LL. В общей форме aʲδ маркеры 0/1
обязаны принадлежать одному X_{t*}, иначе их смесь содержит оба. Для другого Xᵢ пусть замена
его вывода меняет числа a,b на Δa,Δb. Сохраняя маркер 0 получаем Δb=Δa, сохраняя 1 — Δb=2Δa,
поэтому оба изменения нулевые, а строки одинаковы. Следовательно X_{t*} ⇒* aˢ0bʳ и
X_{t*} ⇒* aˢ1b^{n+r}, 0≤s≤k−1. Выбираем n≠n′ с той же парой (X_{t*},s), сохраняя весь
окружающий контекст от n. Подстановка 0-вывода для n′ даёт aⁿ0b^{n−r+r′} ∈ L ⇒ r′=r;
подстановка 1-вывода для n′ даёт aⁿ1b^{n+n′} ∈ L ⇒ n′=n — противоречие.

Это и есть корректное содержание «метода подстановки»: подставляются **выводы нетерминала** в
гипотетической LL(k)-грамматике, а не «конфигурации парсера».

**[ошибка]** `ll_prefix_classes_agent.md`: «Теорема: L — LL(k) ⇔ конечно число k-классов
префиксов». Ложна: у LL(1)-языка {aⁿbⁿ} префиксы aⁿ попарно 1-различимы. Корректный смысл
«префиксных классов» — теорема 4.7.4 [Sh] (все классы Нероуда конечны ⇒ не DCFL ⇒ не LL).
**[ошибка]** `ll_substitution_agent.md`: «после чтения u₁ и u₂ с одинаковым lookahead парсер
находится в одной конфигурации, решения зависят только от lookahead». Ложно (иначе всякий
LL-язык был бы регулярным): конфигурация включает стек. Заменить на аргумент (C).

Известные факты о конкретных языках (для каталога):
- {aⁿbⁿ} ∪ {aⁿcⁿ}, {aⁿ0bⁿ} ∪ {aⁿ1b²ⁿ}: DCFL, не LL (C).
- PAL, {wwᴿ}: не DCFL (1.2) ⇒ не LL. {wcwᴿ}: LL(1).

- {aⁱbʲcᵏ | i = j ∨ j = k}: существенно неоднозначен ⇒ не DCFL ⇒ не LL.

## 1.6. task_wvaavRwR (dcfl_exam_01) — **не DCFL** (эталон `dcfl 0.92` ошибочен)

L = {w v aa vᴿ wᴿ | w ∈ (aa*b)*a, v ∈ b(ab|aa)*} = {x aa xᴿ | x ∈ X}, X = (a⁺b)* ab (ab|aa)*.
Пример в `stack_strategy.md` объявляет «aa» разделителем фаз — но «aa» встречается внутри w (блоки a⁺b)
и внутри v (пары aa), поэтому границу фаз ДМПА не видит; рассуждение несостоятельно.

Теорема 4.7.4 напрямую не применима: bbΣ* — бесконечное множество мёртвых слов.
Наличие повторяющегося «aa» само по себе не доказывает не-DCFL; ниже дано полное сведение.

**Доказательство через продолжение (§1.3).** Предположим L ∈ DCFL и обозначим
K = L_$ ∩ R, где R = (ab)⁺ aa(ba)⁺ $ b aa(ba)⁺ baa(ba)⁺ — регулярный язык.
Запишем слово R как
U = (ab)ʳ aa(ba)ˢ $ b aa(ba)ᵗ baa(ba)ᵘ, r,s,t,u ≥ 1.
Его префикс до $ имеет ровно одно вхождение aa, поэтому принадлежит L только при r = s;
при этом его левая половина (ab)ʳ лежит в X.
После удаления $ получаем
V = (ab)ʳ aab(ab)ˢ aa(ba)ᵗ baa(ba)ᵘ.
В V ровно три вхождения aa. Если V — палиндром, среднее вхождение отражается в себя,
а первое — в третье. Положение среднего aa задаёт разбиение V = H₁ aa H₂ᴿ,
где H₁ = (ab)ʳ aab(ab)ˢ и H₂ = (ab)ᵘ aab(ab)ᵗ.
В каждом H единственное aa, так что H₁ = H₂ эквивалентно r = u и s = t.
Вместе с r = s получаем r = s = t = u = n.
Обратно, при всех показателях n ≥ 1 обе требуемые половины лежат в X:
(ab)ⁿ ∈ X и (ab)ⁿ aab(ab)ⁿ = [(ab)ⁿ aab(ab)ⁿ⁻¹]·ab ∈ (a⁺b)*ab ⊆ X.
Следовательно, доказано точное равенство
K = {(ab)ⁿ aa(ba)ⁿ $ b aa(ba)ⁿ baa(ba)ⁿ | n ≥ 1}.

Осталось доказать K ∉ CFL. Введём новый алфавит {A,B,C,D,E,F,G} и гомоморфизм
h(A)=ab, h(B)=h(C)=h(D)=ba, h(E)=aa, h(F)=$baa, h(G)=baa.
Тогда h⁻¹(K) ∩ A⁺EB⁺FC⁺GD⁺ = {AⁿEBⁿFCⁿGDⁿ | n ≥ 1}.
Это равенство следует из уже доказанного разбора U по единственным разделяющим вхождениям aa
и $, а не из предположения об инъективности h. Если бы K был КС, этот язык тоже был бы КС;
его гомоморфный образ при A↦a, B↦b, C↦c, D,E,F,G↦ε есть {aⁿbⁿcⁿ | n ≥ 1},
не КС — противоречие. По §1.3 L_$ и K были бы DCFL ⊆ CFL, поэтому **L ∉ DCFL**. ∎

Ранее приведённый разбор через Ю не содержал полного доказательства утверждения «единственные
сохраняющие пары — зеркальные»; рассуждение о единственности aa после произвольной накачки
тоже нуждалось в проверке. Конечные `word_instances` этого пробела не закрывают.
В рабочем примере используется доказанное сведение через `prefix_continuation`.

## 1.7. task_u1au2_u3au4 (dcfl_exam_02) — **не DCFL** (эталон `dcfl 0.88` ошибочен)

L = {w₁w₂ | w₁ = u₁au₂, |u₁| ≤ |u₂|; w₂ = u₃au₄, |u₃| ≥ |u₄|}. Первое условие — «есть a в первой половине
w₁» (лучший кандидат — первое a слова), второе — «есть a во второй половине w₂» (лучший кандидат — последнее a).
Отсюда L = {bᵖ a v a bᑫ | v ∈ {a,b}*, |v| ≥ p + q}: разрез между двумя выбранными a
делит v на части длины не меньше p и q, что возможно ровно при |v| ≥ p + q. Выбор первого
и последнего a только ослабляет соответствующие неравенства. Следовательно L ∩ aΣ* = a·L₂,
L₂ = {u₃au₄ | |u₃| ≥ |u₄|} = {v a bᑫ | |v| ≥ q} (a — последнее в слове).

**L₂ ∉ DCFL (теорема 4.7.4).** Мёртвых слов нет (u ↦ u·a ∈ L₂). Для любых слов u,v длин m<n
суффикс z=ab^{m+1} различает их: uz∉L₂, поскольку перед последней a ровно m букв, а после — m+1;
vz∈L₂, поскольку n≥m+1. Значит эквивалентные слова имеют одну длину, и **все классы конечны** ⇒ L₂∉DCFL.
Это охватывает также слова без a и ε. Суффикс bᵗa из старого промпта не различает ничего:
любое слово, оканчивающееся на a, лежит в L₂. DCFL замкнуты относительно ∩REG и левого частного
на слово (a⁻¹L — тот же ДМПА, стартующий из конфигурации после чтения a) ⇒ **L ∉ DCFL**. ∎
Ср.: L₁ = {u₁au₂ | |u₁| ≤ |u₂|} — DCFL (посчитать ведущие b, после первого a снимать по одному).
L₂ — хороший непалиндромный пример для агента shallit.

## 1.10. task_grammar_aSSb (dcfl_exam_04) — **DCFL** (статус установлен) — **[доказано конструкцией, проверено перебором]**

**Задача.** G: S → aSSb | ba | Ab, A → aAb | a. Здесь L(A) = {aⁿ⁺¹bⁿ | n ≥ 0}, поэтому Ab = {aⁿbⁿ | n ≥ 1}, и
L = L(G) — наименьшее множество, содержащее ba и все aⁿbⁿ (n ≥ 1) и замкнутое относительно x, y ∈ L ⇒ axyb ∈ L.
Слова L — кроны бинарных деревьев: внутренняя вершина = a·(потомок₁)(потомок₂)·b, лист = ba или aⁿbⁿ.

**Исторические результаты перебора до длины 30** (не повторялись полностью в этой ревизии).
|L ∩ Σ²ᵐ| = 2, 1, 5, 5, 20, 29, 109, 195, … (m = 1, 2, …). Грамматика G
**неоднозначна**: aabaabbabb = a·[ab]·[a·ab·ba·b]·b = a·[a·ba·ab·b]·[ab]·b (19 неоднозначных слов до длины 14).
L **не префиксно-свободен**: ab, abaabb ∈ L. G не LR(k) ни при каком фиксированном k — из этого **ничего не следует о
языке**: класс DCFL определяется существованием какого-нибудь ДМПА (равносильно — какой-нибудь LR(1)-грамматики [Knuth]),
а не свойствами данной грамматики.

**Где ловушка.** После префикса aⁿ·b·a (n ≥ 2; при n = 1 разбор один) есть два разбора: лист ab — первый потомок (n−1)-й открытой вершины, либо лист ba —
первый потомок n-й вершины. Оба разбора читают дальше один и тот же текст и различаются только «фазами» вершин
(сколько потомков завершено); число открытых вершин у них разное (n−1 и n). Это выглядит как существенный недетерминизм,
и соблазн — заключить «не DCFL». Но **высота стека** у обоих разборов одинакова и равна профилю h(u) = |u|ₐ − |u|_b
(лист ba «проваливается» на уровень родителя и возвращается). Это и есть ключ.

**Теорема.** L ∈ DCFL.

*Доказательство.*
(1) *Профильный НМПА.* Построим НМПА N без ε-переходов, у которого после любого префикса u (кроме u ∈ {b, ba})
высота стека равна h(u). Ячейка стека — «узел» (вершина дерева, открытая буквой a) или «лист-a» (буква a листа aⁿbⁿ).
Фаза узла = число завершённых потомков ∈ {0, 1, 2}; для верхней ячейки она хранится в конечном управлении, для закрытых —
в аннотации ячейки над ней (k = фаза ячейки ниже в момент push). Переходы:
- по a при верхней ячейке «узел с фазой ≤ 1» — недетерминированно положить «лист-a» или «узел» (**единственный
  недетерминизм**: первая буква следующего потомка — начало листа aⁿbⁿ или новой вершины);
- по a при «лист-a в a-фазе» — положить ещё «лист-a»; при «лист-a в b-фазе» или «узел с фазой 2» — нет перехода;
- по b при «лист-a» или «узел с фазой 2» — снять ячейку; фаза ячейки под ней увеличивается на 1;
- по b при «узел с фазой ≤ 1» — начало листа ba: снять ячейку узла, запомнить её фазу в состоянии; по следующему a
  вернуть узел на стек с фазой +1;
- при пустом стеке: слово ba — отдельная ветка конечного управления (два внутренних перехода); принятие — по состоянию D
  (корень закрыт, стек пуст), из D переходов нет.
Корректность следует из инварианта частичного разбора: каждая ячейка узла хранит число завершённых
потомков; цепочка «лист-a» допускает сначала только a, затем только b; аннотация восстанавливает фазу
родителя при закрытии потомка. Временное снятие узла на b допустимо только вместе с последующим a
и завершает ровно лист ba. Начальный выбор соответствует ровно S → aSSb / Ab / ba; закрытие
корня допустимо ровно после завершения всего дерева. Эти переходы воспроизводят каждый вывод G,
и каждый принимающий путь N по тому же инварианту восстанавливает вывод G (индукция по префиксу).
Проверено перебором: L(N) совпадает с L на всех 2¹⁹ − 2 словах длины ≤ 18 и содержит все 410 677 слов L длины ≤ 30.

(2) *Height-determinism.* Каждый переход по a увеличивает высоту на 1, каждый по b — уменьшает на 1 (кроме ветки ba при
пустом стеке, где высота 0 у всех вычислений). Значит, все вычисления N на одном входе имеют одну и ту же высоту стека:
N — real-time height-deterministic pda (*rhpda*) в смысле [NS, Def. 2] (нормализация [NS, Def. 1]: все правила уже имеют вид
pX → qλ | qX | qYX; полнота достигается sink-веткой с той же функцией высоты — на ⊥ по b она делает внутренний переход, по a
кладёт символ, а одновременно с веткой ba живых вычислений N нет).

(3) *Детерминизация.* [NS, Theorem 4]: rhCFL = rdCFL — для всякого rhpda A строится детерминированный rhpda B с L(B) = L(A)
и той же функцией высоты, с 2^{O(n²)} состояниями (n — число пар (состояние, символ стека) у A). Конструкция та же, что при
детерминизации visibly pushdown automata [AM]: символ стека ДМПА на уровне i — множество троек (p, X, q), где p —

## 2.4. Interchange lemma — точная формулировка; Соколовский — удалить

**Лемма 4.5.1 [Sh] (Ogden–Ross–Winklmann 1985).** Для всякого КС-языка L существует c > 0 такое, что для всех
n ≥ m ≥ 2 и всякого R ⊆ L ∩ Σⁿ найдётся Z = {z₁,…,z_k} ⊆ R с k ≥ |R| / (c(n+1)²) и разложениями zᵢ = wᵢxᵢyᵢ:
(a) |w₁| = … = |w_k|; (b) |y₁| = … = |y_k|; (c) m/2 < |x₁| = … = |x_k| ≤ m; (d) wᵢxⱼyᵢ ∈ L для всех i, j.

**[ошибка]** `cfl_interchange.md`: «для любого множества S из n слов одной длины найдутся два взаимозаменяемых» —
потеряна количественная нижняя оценка: при |R| = O(n²) она может не гарантировать даже k ≥ 2. Example 2
({xyz | |x|=|y|=|z|, x≠y, y≠z}, «Ω(n²) слов, принцип Дирихле») — недоказательство; удалить.
Одна достаточная схема применения: взять R экспоненциального размера внутри «жёсткого» регулярного шаблона, показать,
что взаимозаменяемость вынуждает xᵢ = xⱼ, и получить |Z| ≤ 2^{n/8} < 2^{n/4}/(c(n+1)²). Учебный пример
[Sh, Thm 4.5.4]: L₆ = {xyyz | y ≠ ε} над 6-буквенным алфавитом не КС (бесквадратные слова Туэ–Морса +
идеальное перемешивание). Для экзаменационных языков над {a,b,c} лемма почти не нужна — агент должен
предпочитать накачку/Огдена и честно возвращать inconclusive.
Уточнение подсчёта: равенство всех средних блоков само по себе не ограничивает число слов числом значений
этого блока. Нужно оценить число допустимых **контекстов** wᵢ,yᵢ при фиксированном x. В примере [Sh, Thm 4.5.4]
именно оставшиеся свободные позиции дают 2^{n/8}. Экспоненциальный размер R и большой алфавит — приёмы
этого примера, не дополнительные условия леммы; для другого доказательства достаточно любой строгой
верхней оценки |Z|, противоречащей |R|/(c(n+1)²).

**Лемма Соколовского** (IPL 1978): формулировка в промпте («…имеет определённую структуру») не соответствует
источнику и непроверяема ⇒ удалить из `cfl_interchange.md`, `cfl_retry_planner.md` (`try_sokolowski`),
`tz_cfl_agent_system.md` (enum method).

## 3.4. LL: лемма об ограниченной гибкости — **[доказано]**; два DCFL-не-LL языка

**Лемма (ограниченная гибкость конечного унарного хвоста; локальное доказательство).** Пусть G —
однозначная КС-грамматика, S ⇒* uδ, u — терминальное слово, и ∅≠L(δ)⊆b* **конечно**.
Тогда диаметр множества длин L(δ) не превосходит константы W_G, зависящей только от G.
Можно взять W_G = Σ_X(max{|v|:v∈L(X)}−min{|v|:v∈L(X)}), где сумма по всем нетерминалам G
с конечным непустым языком L(X)⊆b*. *Доказательство.* Каждый X в δ продуктивен, и его язык
унарен и конечен: иначе, фиксируя выводы остальных символов, получаем неунарное или бесконечное
L(δ). Если X с двумя различными значениями bʳ,bˢ встречается в δ дважды, перестановка этих
двух выводов в достижимой форме uδ даёт одно слово с двумя деревьями. Значит каждый такой X
встречается не более одного раза. Остальные символы добавляют фиксированные длины; суммарный
диаметр ограничен W_G. ∎ Прежняя формулировка через «ограниченное число продолжений» не уточняла
фиксированный префикс u и не обосновывала конечность L(δ); применять нужно именно эту версию.

**Теорема.** L = {aⁱbʲ | i ≥ j ≥ 0} не LL(k) ни при каком k (при этом {aⁱbʲ | i ≤ j} — LL(1): S → TB, T → aTb | ε,
B → bB | ε). *Доказательство.* Пусть G — LL(k), n > k + W_G. Слова aⁿbᵏ и aⁿbⁿ совпадают на первых n + k символах,
поэтому их левые выводы совпадают до формы aⁿbʳδ с 1 ≤ r ≤ k (ℓ=n+k в §3.3 (C));
∅≠L(δ)⊆{bᵗ:0≤t≤n−r}, поскольку u=aⁿbʳ фиксирован. В частности, L(δ) конечно,
δ ⇒* b^{k−r} и δ ⇒* b^{n−r}. По лемме n−k≤W_G — противоречие. ∎

**Следствие: {w b* c wᴿ | w ∈ {a,b}*} — DCFL, но не LL(k).** Слова bᴹcbʲ (j ≤ M) лежат в L; после префикса bᴹc bʳ
допустимы только b^{≤M−r}; при M>k+W_G выводы bᴹcbᵏ и bᴹcbᴹ совпадают до формы bᴹcbʳδ
(ℓ=M+1+k, 1≤r≤k), поэтому применима та же конечная унарная лемма. Это прямое доказательство
для L, а не вывод из пересечения с REG. DCFL: ДМПА кладёт весь префикс до c на стек; после c
снимает b по входу. Первый прочитанный a удерживает в состоянии, удаляет оставшиеся верхние b
ε-шагами, затем сверяет a и весь остаток точно. Если a справа не встретился, на конце входа
разрешается остаток стека только из b; иначе требуется пустой стек. Эти фазы детерминированы.
**[ошибка]** В `ll_classifier.md` (Example 2), `ll_marker_analyzer.md` (Example 1), `ll_grammar_builder.md`
(Example 1) и моках `wbcwR_*` этот язык объявлен LL(1). Заменить вердикт на not_ll (метод: substitution/(C)+лемма
об ограниченной гибкости) либо сменить пример на {w b c wᴿ} с одиночным b — он LL(1): S → aSa | bT,
T → c | aSab | bTb (FIRST попарно дизъюнктны).

Каталог (дополнить §3.3): {aⁱbʲ | i ≥ j}, {bᴹcbʲ | j ≤ M}, {w b* c wᴿ} — DCFL, не LL; {aⁱbʲ | i ≤ j}, {w c wᴿ},
{w b c wᴿ} — LL(1).
