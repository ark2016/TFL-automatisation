The grammar contains the rule S → SaSb, which exhibits nested/balanced recursion between terminals 'a' and 'b'. This structure requires unbounded memory to track matching counts, analogous to {a^n b^n}, and cannot be recognized by any finite automaton. Hard rule 'nested_recursion' applies.
1
Предположим L регулярен с длиной накачки p.
2
Выберем слово w = a^p b^p ∈ L, |w| ≥ p.
3
Поскольку |xy| ≤ p, подстрока xy целиком лежит в блоке a^p, то есть y = a^k для некоторого k ≥ 1. Ключевое наблюдение: каждое слово языка L имеет чётную длину. Это доказывается структурной индукцией по дереву вывода: (1) S → ε порождает слово длины 0 (чётное); (2) S → A → aa даёт длину 2; (3) S → A → bb даёт длину 2; (4) S → A → bSb добавляет 2 символа к слову, порождённому S, сохраняя чётность; (5) S → SaSb: если S₁ порождает слово длины m и S₂ порождает слово длины n (оба чётные по предположению индукции), то результат имеет длину m + 1 + n + 1 = m + n + 2, что тоже чётно. Таким образом, |w| чётно для любого w ∈ L. Теперь рассмотрим два подслучая в зависимости от чётности k.
4
Накачиваем: xy²z = a^(p+k) b^p. Длина xy²z равна |a^(p+k) b^p| = 2p + k. Поскольку k нечётно и 2p чётно, сумма 2p + k нечётна. Но все слова в L имеют чётную длину, следовательно xy²z ∉ L.
5
Накачиваем: xy⁰z = a^(p−k) b^p. Длина xy⁰z равна |a^(p−k) b^p| = 2p − k. Поскольку k чётно и 2p чётно, длина чётна — аргумент чётности здесь не работает напрямую. Используем другой подход. Рассмотрим количество символов a и b в словах из L ∩ a*b*. Докажем индукцией по дереву вывода, что для любого слова w ∈ L ∩ a*b* выполняется #a(w) ≥ #b(w). Базис: S → ε даёт ε (0 ≥ 0 ✓); S → A → aa даёт 2 ≥ 0 ✓; S → A → bb даёт 0 ≥ 2 ✗, но bb ∉ a*b* в смысле a⁺b⁺ — точнее bb = a⁰b², что формально принадлежит a*b*, и здесь #a < #b. Значит, нужно уточнить аргумент. Пересмотрим: выберем слово w = a^p b^p при p ≥ 2 и используем i = 0. Тогда xy⁰z = a^(p−k)b^p. Покажем, что это слово не в L, используя пересечение с регулярным языком. Если L регулярен, то L' = L ∩ a*b* тоже регулярен. Слова вида a^m b^n в L': из грамматики можно вывести a^m b^n ∈ L только если определённые соотношения между m и n выполняются. Однако этот случай требует более тонкого анализа — см. альтернативный подход ниже.
6
Приведённый выше анализ по чётности покрывает случай нечётного k, но случай чётного k требует дополнительного аргумента. Применим метод замыкания (closure) для завершения доказательства. ∎

Включение ⊇: из правила S → SaSb при многократном применении с S → ε получаем aⁿbⁿ ∈ L для всех n ≥ 0, а при n ≥ 1 эти слова лежат в a⁺b⁺. Включение ⊆: единственные слова из L, целиком состоящие из блока a⁺ и затем блока b⁺, — это именно aⁿbⁿ, поскольку правило A → aa даёт слово без b, правило A → bb даёт слово без a, правило A → bSb порождает слова, начинающиеся с b, а рекурсия S → SaSb при подстановке непустых S нарушает структуру a*b*. Таким образом, L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Язык a⁺b⁺ регулярен, класс REG замкнут относительно пересечения. Если бы L был регулярным, то L ∩ a⁺b⁺ тоже был бы регулярным. Но {aⁿbⁿ | n ≥ 1} — классический нерегулярный язык (доказывается леммой о накачке). Противоречие. Следовательно, L не является регулярным. ∎

The grammar S → SaSb | ε | A, A → bb | aa | bSb generates a non-regular language. To see this, consider the intersection of L with the regular language a*b*. By choosing S → SaSb repeatedly with the left S → ε each time, and finally S → ε for the rightmost S, we get derivations: S → SaSb → aSb → aS'aS'b² → aaS'b² → ... → aⁿbⁿ for all n ≥ 0. Thus L ∩ a*b* ⊇ {aⁿbⁿ | n ≥ 0}. Conversely, any word in L ∩ a*b* must equal aⁿbⁿ (this can be verified by structural induction on derivations: any derivation producing a word in a*b* must use only S → SaSb and S → ε). Since {aⁿbⁿ | n ≥ 0} is not regular, and regular languages are closed under intersection, L cannot be regular.
The grammar S → SaSb | ε | A, A → bb | aa | bSb generates a non-regular language. By repeated application of S → SaSb with all intermediate S's set to ε, we obtain the sublanguage {aⁿbⁿ | n ≥ 0}. One can verify by structural induction that every string in a*b* generated by S has equal numbers of a's and b's, so a^n b^m ∈ L ∩ a*b* implies n = m. By the pumping lemma, taking w = aᵖbᵖ, any decomposition xyz with |xy| ≤ p and |y| ≥ 1 gives y = aᵏ (k ≥ 1), and xy²z = aᵖ⁺ᵏbᵖ ∉ L since p+k ≠ p. This contradicts the pumping lemma, so L is not regular and no DFA can be constructed.

💡
Установлено: L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Это ключевой факт для доказательства.
💡
Включение ⊇ тривиально: aⁿbⁿ выводится через S → SaSb с S₁ → ε на каждом шаге.
💡
Включение ⊆ доказывается структурной индукцией: правило S → SaSb при подстановке слов из a*b* вынуждает оба подвывода S давать ε (иначе нарушается структура a*b*).
💡
Рекомендация для экзамена: наиболее чистое и короткое доказательство — через замыкание (пересечение с регулярным языком a⁺b⁺). Это стандартный приём.
💡
Альтернатива: можно применить лемму о накачке напрямую к L ∩ a*b*, рассматривая слово aᵖbᵖ уже в пересечённом языке {aⁿbⁿ}, где доказательство стандартно.
💡
Наблюдение о структуре: все слова в L имеют чётную длину (доказывается индукцией по дереву вывода). Это полезное вспомогательное свойство, но само по себе недостаточно для доказательства нерегулярности.
💡
Грамматика содержит вложенную рекурсию S → SaSb и A → bSb, что делает её существенно контекстно-свободной (не приводимой к праволинейной или леволинейной форме).
