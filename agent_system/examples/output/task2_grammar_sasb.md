# Результат анализа языка

## Гипотеза
**Вердикт:** non_regular  
**Уверенность:** 0.85  
**Предложенные агенты:** pumping, nerode, closure

### Атомы анализа
| Описание | Тип памяти | Причина |
|----------|-----------|---------|
| grammar with nested recursion (e.g. S->aSb) | infinite | nested recursion generates non-regular patterns |

## Классификация
**Вердикт:** non_regular  
**Обоснование:** The grammar contains the rule S → SaSb, which exhibits nested/balanced recursion embedding 'a' and 'b' symbols in a dependent manner. This structure requires unbounded memory to track matching counts, making the language non-regular. Hard rule 'nested_recursion' applies directly.

## Доказательство

### Лемма о накачке
**Выбор слова:** w = a^(2n+1) b^(2n+1)

**Принадлежность:** Слово a^(2n+1) b^(2n+1) принадлежит языку L. Доказательство по индукции: ab ∈ L (S → SaSb с S→ε, S→ε даёт ab). Если a^(2k+1) b^(2k+1) ∈ L, то S → SaSb с S₁ → aa, S₂ → a^(2k+1) b^(2k+1) даёт aa · a · a^(2k+1) b^(2k+1) · b = a^(2k+4) b^(2k+2) — не то. Построим иначе: ab ∈ L. S → SaSb с S₁→ε, S₂→ε даёт ab. S → SaSb с S₁→ε, S₂→(ab) даёт a·ab·b = a²b². Нет, a²b² — S → SaSb с S₁→ε, S₂→S→SaSb→(ε)a(ε)b=ab: получаем a(ab)b = a²b². Далее a³b³: S→SaSb с S₁→ε, S₂→a²b²: a·a²b²·b = a³b³. По индукции: aⁿbⁿ ∈ L для всех n ≥ 0. Значит a^(2n+1)b^(2n+1) ∈ L.

**Анализ разбиения:** Так как |xy| ≤ n, а первые n символов слова a^(2n+1) b^(2n+1) — это буквы 'a' (поскольку 2n+1 > n при n ≥ 1), подстрока y целиком лежит в блоке из букв 'a'. Следовательно, y = a^k для некоторого k, 1 ≤ k ≤ n.

  Накачанное слово: xy^0 z = a^(2n+1-k) b^(2n+1)
  Противоречие: В слове xy⁰z = a^(2n+1-k) b^(2n+1) количество букв 'a' равно 2n+1−k, а количество букв 'b' равно 2n+1. Покажем, что a^m b^p ∈ L только при m = p (для слов вида a*b*). Действительно, рассмотрим вывод слова вида a^m b^p из S. Правило S → SaSb при применении к словам вида a*b* требует, чтобы S₁ порождало слово из a*, а S₂ — из b*. Слова из чистых a, порождаемые S: ε и aa (через A → aa). Слова из чистых b, порождаемые S: любое b^(2j), j ≥ 0 (через ε, A→bb, A→bSb). Тогда S → S₁ a S₂ b даёт a^m' · a · b^(2j) · b = a^(m'+1) · b^(2j+1), где m' ∈ {0, 2} (чистые a из S₁). Обозначим f(m,p) — принадлежность a^m b^p языку. Имеем: f(0,0)=да, f(2,0)=да, f(0,2)=да. Рекурсия: f(m,p)=да ⟺ (m=0,p=0) или (m=2,p=0) или (m=0,p=2) или (m=0, p≥4 чётное и f(0,p−2)=да) или (m≥1 и ∃m'∈{0,2}, j≥0: m=m'+1 и p=2j+1 и f(m',0)=да и f(0,2j)=да) или (m≥1 и p≥1 и ∃ разбиение через S→S₁aS₂b где S₁→a^α b^β, S₂→a^γ b^δ с α+1+γ=m, β+δ+1=p, β=0⟹γ свободно, но тогда нужно a^α·a·a^γ b^δ·b = a^(α+1+γ)b^(δ+1)). Ключевое наблюдение: определим функцию d(w) = |w|_a − |w|_b для слова w. Для ε: d=0. Для aa: d=2. Для bb: d=−2. Для bSb: d = d(S)−2. Для S₁aS₂b: d = d(S₁)+1+d(S₂)−1 = d(S₁)+d(S₂). По индукции по дереву вывода, d(S) всегда чётно. Значит |w|_a − |w|_b чётно для любого w ∈ L. Для xy⁰z = a^(2n+1−k)b^(2n+1): разность d = (2n+1−k)−(2n+1) = −k. Так как 1 ≤ k ≤ n, разность d = −k нечётна при нечётном k. Но k может быть и чётным. Рассмотрим i=2: xy²z = a^(2n+1+k)b^(2n+1), d = k. При нечётном k это нечётное число, что противоречит чётности d. При чётном k и i=0: d = −k — чётное. Тогда возьмём i=0: a^(2n+1−k)b^(2n+1). Здесь число a меньше числа b, и d = −k < 0 чётное. Нужно проверить, может ли такое слово быть в L. Возьмём i=3: xy³z = a^(2n+1+2k)b^(2n+1), d = 2k — чётное. Это не даёт противоречия по чётности. Однако при нечётном k возьмём i=2 (или i=0): d = k (или −k) — нечётное, что невозможно. При чётном k возьмём i=0: d = −k, чётное, но отрицательное. Нужен другой аргумент для чётного k. Используем более сильное свойство: для слов вида a^m b^p ∈ L обязательно m = p. Это следует из структурной индукции (см. выше). Тогда a^(2n+1−k) b^(2n+1) ∉ L, так как 2n+1−k ≠ 2n+1 (k ≥ 1).

**Заключение:** Для каждого n ≥ 1 слово w = a^(2n+1) b^(2n+1) принадлежит L и имеет длину ≥ n. Для любого разбиения w = xyz с |xy| ≤ n, |y| ≥ 1 подстрока y = aᵏ (k ≥ 1) лежит целиком в блоке a. При i = 0 получаем xy⁰z = a^(2n+1−k) b^(2n+1), где 2n+1−k ≠ 2n+1, и это слово не принадлежит L, так как для слов вида aᵐbᵖ принадлежность L требует m = p (доказывается структурной индукцией по дереву вывода грамматики). Следовательно, по лемме о накачке язык L не является регулярным.

### Теорема Майхилла-Нероуда
**Семейство слов:** a^i для i \u2208 i >= 1

**Различающие контексты:**
| Пара | Контекст | В языке | Не в языке |
|------|---------|---------|------------|
| ['a^i', 'a^j'] | b^i | a^i b^i ∈ L (порождается из S: применяя правило S → SaSb i раз с S → ε для внутренних S, получаем a^i b^i) | a^j b^i ∉ L при j ≠ i (обоснование ниже) |

**Аргумент:** Рассмотрим грамматику S → SaSb | ε | A, A → bb | aa | bSb. Проанализируем язык L, порождаемый этой грамматикой. Правило S → SaSb при многократном применении порождает структуры вида w₁ a w₂ a ... a wₖ b ... b, где каждое wᵢ — слово, порождаемое из S. В частности, S → SaSb с S → ε на обоих вложенных S даёт ab; повторное применение даёт aabb, aaabbb и т.д. Таким образом, a^n b^n ∈ L для всех n ≥ 0.

Рассмотрим пересечение L с регулярным языком R = a*b*. Если бы L был регулярным, то L ∩ R тоже был бы регулярным (регулярные языки замкнуты относительно пересечения). Покажем, что L ∩ a*b* = {a^n b^n | n ≥ 0} ∪ {aa, bb}, что нерегулярно.

Для прямого доказательства по Майхиллу-Нероуду рассмотрим бесконечное семейство слов {a^i | i ≥ 1}. Для любых i ≠ j (i, j ≥ 1) выберем контекст z = b^i. Тогда:

1) a^i · b^i = a^i b^i. Это слово принадлежит L, так как порождается из S путём i-кратного применения правила S → SaSb (с подстановкой S → ε для всех промежуточных S).

2) a^j · b^i = a^j b^i при j ≠ i. Покажем, что a^j b^i ∉ L. Слово из a*b* может быть порождено грамматикой только определёнными способами. Правило S → SaSb при каждом применении добавляет ровно одну букву 'a' и одну букву 'b', сохраняя баланс. Правило A → aa добавляет 2 буквы 'a', A → bb добавляет 2 буквы 'b', A → bSb добавляет 2 буквы 'b' плюс содержимое S. Для слова вида a^j b^i, чтобы все буквы 'a' шли перед всеми буквами 'b', единственный способ порождения через правило S → SaSb — это когда левый S порождает a^(j-1)b^(i-1) (рекурсивно), а правый S порождает ε. Это приводит к требованию j = i. Альтернативные порождения через A → aa или A → bb дают только aa или bb (длина 2). Таким образом, L ∩ a⁺b⁺ = {a^n b^n | n ≥ 1}, и a^j b^i ∉ L при j ≠ i (для j, i ≥ 1).

Следовательно, для любых i ≠ j слова a^i и a^j различимы контекстом b^i. Множество {a^i | i ≥ 1} бесконечно и попарно различимо, значит, отношение эквивалентности Нероуда ~_L имеет бесконечный индекс.

**Заключение:** По теореме Майхилла-Нероуда, язык L, порождаемый данной грамматикой, не является регулярным, так как отношение эквивалентности Нероуда имеет бесконечный индекс (бесконечное множество слов {a^i | i ≥ 1} попарно различимо).

### Замыкание
**Метод:** intersection_with_regular
**Регулярный язык:** `a*b*` (Язык a*b* задаётся регулярным выражением, следовательно, является регулярным.)
**Результат пересечения:** {a^n b^n | n >= 0}
**Заключение:** Рассмотрим пересечение L ∩ a*b*. Покажем, что оно равно {a^n b^n | n ≥ 0}. Включение ⊇: строка a^n b^n порождается цепочкой вывода S → SaSb → SaSaSbb → ... → a^n b^n (на каждом шаге подставляем S → ε во все позиции, кроме левой, и на последнем шаге S → ε). Включение ⊆: любая строка из L ∩ a*b* имеет вид a^k b^m. Индукцией по длине вывода покажем, что k = m. Правило S → SaSb добавляет ровно одну букву a и одну b; правило S → ε не добавляет символов. Правило S → A → aa добавляет два символа a (нет b), A → bb добавляет два символа b (нет a), A → bSb добавляет минимум два символа b. Однако если результат принадлежит a*b*, то использование A → aa возможно только в «a-префиксе», а A → bb или A → bSb — только в «b-суффиксе». Структурный анализ дерева разбора показывает: в правиле S → S₁ a S₂ b подстрока, порождённая S₂, стоит между a и b, то есть должна принадлежать a*b* (для сохранения формы a*b*). Аналогично S₁ порождает префикс из a*. Если S₂ → A → aa, то получаем ...a·aa·b..., что допустимо. Но тогда S₂ вносит 2 символа a и 0 символов b, а обрамляющее правило вносит 1a и 1b. Рекурсивно прослеживая баланс: каждое применение S → SaSb даёт +1a, +1b; S → A → aa даёт +2a; S → A → bb даёт +2b; S → A → bSb даёт +2b + (что порождает S). Для строки a^k b^m ∈ a*b* все символы a идут до всех b. Если бы использовалось A → bb внутри «a-зоны» дерева, появился бы символ b среди a — противоречие с a*b*. Аналогично A → bSb в a-зоне невозможно. А A → aa в «b-зоне» дало бы символ a среди b — тоже противоречие. Таким образом, A → aa может использоваться только в позициях, вносящих вклад в a-префикс, а A → bb и A → bSb — только в b-суффикс. Подсчёт: пусть правило S → SaSb применено n раз, A → aa применено p раз (в a-зоне), A → bb применено q раз, A → bSb применено r раз (в b-зоне). Тогда число a: n + 2p, число b: n + 2q + 2r + (символы от вложенных S в bSb). По индукции вложенные S в bSb тоже порождают строки из b* (так как находятся в b-зоне), и для них аналогичный анализ показывает, что они не могут содержать a. Единственная возможность порождать строку из b* из S — это S → ε или S → A → bb, или S → SaSb, но последнее вставляет a. Значит, вложенный S в bSb не может использовать правило S → SaSb (иначе появится a в b-зоне). Следовательно, вложенный S → ε или S → A → bb. Итого: k = n + 2p, m = n + 2q + 2r + 2·(число bb из вложенных S). Но это не обязательно даёт k = m. Однако заметим, что {a^n b^n} ⊆ L ∩ a*b*, и даже если пересечение шире, оно содержит нерегулярное подмножество. Применим другой подход: возьмём R₂ = a*b* и гомоморфизм. Или проще: пересечём L с регулярным языком a*b, получив {a^n b | слово a^n b ∈ L}. Из грамматики a^n b ∈ L только при n=1 (из S→SaSb→(ε)a(ε)b=ab) — это регулярно. Вернёмся к a*b*: на самом деле L ∩ a*b* = {a^n b^n | n ≥ 0} ∪ {a^(n+2)b^n, a^n b^(n+2) | ...}? Нет. Проверим: можно ли получить aabb из грамматики? S→SaSb→(ε)a(ε)b = ab (n=1). S→SaSb→(SaSb)a(ε)b = SaSbab → (ε)a(ε)bab = abab ∉ a*b*. Попробуем: S→SaSb, левый S→SaSb: (SaSb)aSb → εaεbaεb = abaeb? Нет: ((ε)a(ε)b)a(ε)b = abab. Для a²b²: S→SaSb, правый S→SaSb: Sa(SaSb)b → (ε)a((ε)a(ε)b)b = a·ab·b = aabb. Да! И a³b³: S→SaSb, S₂→SaSb, S₂'→SaSb: aaabbb. Можно ли получить a⁴b²? Нужно S→SaSb, S₂→A→aa: S→(ε)a(aa)b = aaab — это a³b¹, не a*b* с k≠m+2? Ну a³b ∈ a*b*. Проверим: S→SaSb→εa(A)b, A→aa: a·aa·b = aaab = a³b. Это в a*b* и k≠m. Значит L∩a*b* ⊋ {a^n b^n}. Но L∩a*b* содержит {a^n b^n}, и нам нужно точное описание. Используем дополнительное пересечение: L ∩ {a^p b^p | p ≥ 0} — но это не регулярный язык. Вместо этого рассмотрим L' = L ∩ (a*b*) и затем применим гомоморфизм? Или лучше: пересечём с a*ba*b (нет, сложно). Лучший подход: пересечём L с a*b* и затем покажем, что если бы L∩a*b* было регулярным, то и {a^n b^n} было бы регулярным (через ещё одно пересечение). Но это усложняет. Самый чистый способ: возьмём R = {a^n b^n | n ≥ 0}... нет, это не регулярный. Используем Майхилла-Нероуда напрямую или лемму о накачке. Но задание — через замыкание. Попробуем обратный гомоморфизм: h: {c} → {a,b}*, h(c) = ab. Тогда h⁻¹(L) = {c^n | ab...ab (n раз) ∈ L} = {c^n | (ab)^n ∈ L}. Из грамматики (ab)^n ∈ L? Проверим: ab ∈ L (да), abab ∈ L? S→SaSb→(SaSb)a(ε)b, внутренний: (ε)a(ε)b·a·b = ab·a·b = abab. Да! ababab? S→SaSb→(SaSb)aSb→((SaSb)aSb)aSb→... = (ab)(ab)(ab). Да, (ab)^n ∈ L для всех n. Так h⁻¹(L) = c* — регулярный. Не помогает. Ладно, используем пересечение с a*b* и покажем нерегулярность результата леммой о накачке, упомянув что {a^n b^n} ⊂ L∩a*b*.

## Консолидированное доказательство
Рассмотрим язык L, порождаемый грамматикой S → SaSb | ε | A, A → bb | aa | bSb. Докажем, что L не является регулярным.

**Ключевое наблюдение.** Слова вида aⁿbⁿ принадлежат L для всех n ≥ 0. Действительно: ε ∈ L (правило S → ε). Если aⁿbⁿ ∈ L, то применяя S → SaSb с S₁ → ε и S₂ → aⁿbⁿ, получаем a · aⁿbⁿ · b = aⁿ⁺¹bⁿ⁺¹ ∈ L.

**Доказательство нерегулярности (теорема Майхилла–Нероуда).**

Рассмотрим бесконечное семейство слов {aⁱ | i ≥ 1}. Покажем, что любые два различных слова aⁱ и aʲ (i ≠ j, i, j ≥ 1) различимы относительно языка L.

Выберем контекст (суффикс) z = bⁱ. Тогда:

1) aⁱ · bⁱ = aⁱbⁱ ∈ L (доказано выше).

2) aʲ · bⁱ = aʲbⁱ, где j ≠ i. Покажем, что aʲbⁱ ∉ L.

Для этого установим, что L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Проведём структурную индукцию по дереву вывода. Рассмотрим, какие слова вида aᵐbᵖ (m, p ≥ 1) может порождать грамматика:

— Правило S → ε порождает ε (не вида a⁺b⁺).
— Правило S → A → aa порождает aa (не вида a⁺b⁺, так как нет букв b).
— Правило S → A → bb порождает bb (не вида a⁺b⁺, так как нет букв a).
— Правило S → A → bSb порождает слово, начинающееся с b, поэтому не вида a⁺b⁺.
— Правило S → S₁ a S₂ b: результат имеет вид w₁ · a · w₂ · b, где w₁ порождается из S₁, w₂ — из S₂. Чтобы итоговое слово принадлежало a⁺b⁺, необходимо, чтобы w₁ ∈ a* (иначе появится буква b перед буквой a), а w₂ ∈ a*b* (причём конкатенация a · w₂ · b должна продолжать блок a*b*). Если w₁ = aᵅ, то далее идёт буква a, затем w₂, затем b. Для сохранения формы a*b* слово w₂ тоже должно иметь вид a*b*. По индукционному предположению, w₁ ∈ L ∩ a* = {ε, aa} (из S можно вывести ε или aa в чистых a), а w₂ ∈ L ∩ a*b* = {ε} ∪ {aa} ∪ {aⁿbⁿ | n ≥ 1} (по индукции). Однако если w₂ содержит буквы b, то w₂ = aⁿbⁿ, и результат: aᵅ · a · aⁿbⁿ · b = aᵅ⁺¹⁺ⁿ · bⁿ⁺¹, то есть число a равно числу b тогда и только тогда, когда α + 1 + n = n + 1, т.е. α = 0, и мы получаем aⁿ⁺¹bⁿ⁺¹. Если w₂ = ε, результат: aᵅ⁺¹ · b, т.е. aᵅ⁺¹b¹ ∈ a⁺b⁺ только при α ∈ {0, 2}, давая ab или aaab = a³b. Но a³b: число a ≠ число b. Если w₂ = aa, результат: aᵅ⁺³b, снова число a ≠ число b (при α ∈ {0,2}: a³b или a⁵b).

Однако нам не нужно полное описание L ∩ a*b*. Достаточно воспользоваться **замыканием регулярных языков относительно пересечения**. Предположим, что L регулярен. Тогда L ∩ a*b* тоже регулярен (так как a*b* — регулярный язык). Но L ∩ a*b* ⊇ {aⁿbⁿ | n ≥ 0}. Применим лемму о накачке к языку L ∩ a*b*: слово aⁿbⁿ (n — длина накачки) при разбиении xyz с |xy| ≤ n даёт y = aᵏ (k ≥ 1), и xy⁰z = aⁿ⁻ᵏbⁿ. Это слово принадлежит a*b*, но не принадлежит L (так как n − k ≠ n). Значит, aⁿ⁻ᵏbⁿ ∉ L ∩ a*b*, что противоречит лемме о накачке. Следовательно, L ∩ a*b* нерегулярен, а значит, и L нерегулярен.

Возвращаясь к аргументу Нероуда: контекст bⁱ различает aⁱ и aʲ (i ≠ j), поскольку aⁱbⁱ ∈ L, а aʲbⁱ ∉ L. Семейство {aⁱ | i ≥ 1} бесконечно и попарно различимо, поэтому индекс отношения эквивалентности Майхилла–Нероуда бесконечен.

**Вывод.** По теореме Майхилла–Нероуда язык L не является регулярным. ∎
