# Результат анализа языка

## Гипотеза
**Вердикт:** non_regular  
**Уверенность:** 0.85  
**Предложенные агенты:** pumping, nerode, closure

### Атомы анализа
| Описание | Тип памяти | Причина |
|----------|-----------|---------|
| grammar with nested recursion (e.g. S->aSb) | infinite | nested recursion generates non-regular patterns |

## Классификация
**Вердикт:** non_regular  
**Обоснование:** The grammar contains the rule S → SaSb, which exhibits nested/balanced recursion between terminals 'a' and 'b'. This structure requires unbounded memory to track matching counts, analogous to {a^n b^n}, and cannot be recognized by any finite automaton. Hard rule 'nested_recursion' applies.

## Доказательство

### Регулярное выражение
`None` — The grammar S → SaSb | ε | A, A → bb | aa | bSb generates a non-regular language. To see this, consider the intersection of L with the regular language a*b*. By choosing S → SaSb repeatedly with the left S → ε each time, and finally S → ε for the rightmost S, we get derivations: S → SaSb → aSb → aS'aS'b² → aaS'b² → ... → aⁿbⁿ for all n ≥ 0. Thus L ∩ a*b* ⊇ {aⁿbⁿ | n ≥ 0}. Conversely, any word in L ∩ a*b* must equal aⁿbⁿ (this can be verified by structural induction on derivations: any derivation producing a word in a*b* must use only S → SaSb and S → ε). Since {aⁿbⁿ | n ≥ 0} is not regular, and regular languages are closed under intersection, L cannot be regular.

### ДКА
The grammar S → SaSb | ε | A, A → bb | aa | bSb generates a non-regular language. By repeated application of S → SaSb with all intermediate S's set to ε, we obtain the sublanguage {aⁿbⁿ | n ≥ 0}. One can verify by structural induction that every string in a*b* generated by S has equal numbers of a's and b's, so a^n b^m ∈ L ∩ a*b* implies n = m. By the pumping lemma, taking w = aᵖbᵖ, any decomposition xyz with |xy| ≤ p and |y| ≥ 1 gives y = aᵏ (k ≥ 1), and xy²z = aᵖ⁺ᵏbᵖ ∉ L since p+k ≠ p. This contradicts the pumping lemma, so L is not regular and no DFA can be constructed.

### Лемма о накачке
**Выбор слова:** w = a^p b^p

**Принадлежность:** Слово a^p b^p принадлежит L, так как оно выводится применением правила S → SaSb ровно p раз (каждый раз раскрывая самый левый S), после чего все оставшиеся нетерминалы S заменяются на ε. Например: S ⇒ SaSb ⇒ SaSaSbb ⇒ ... ⇒ a^p b^p.

**Анализ разбиения:** Поскольку |xy| ≤ p, подстрока xy целиком лежит в блоке a^p, то есть y = a^k для некоторого k ≥ 1. Ключевое наблюдение: каждое слово языка L имеет чётную длину. Это доказывается структурной индукцией по дереву вывода: (1) S → ε порождает слово длины 0 (чётное); (2) S → A → aa даёт длину 2; (3) S → A → bb даёт длину 2; (4) S → A → bSb добавляет 2 символа к слову, порождённому S, сохраняя чётность; (5) S → SaSb: если S₁ порождает слово длины m и S₂ порождает слово длины n (оба чётные по предположению индукции), то результат имеет длину m + 1 + n + 1 = m + n + 2, что тоже чётно. Таким образом, |w| чётно для любого w ∈ L. Теперь рассмотрим два подслучая в зависимости от чётности k.

  Накачанное слово: xy²z = a^(p+k) b^p
  Противоречие: Длина xy²z равна |a^(p+k) b^p| = 2p + k. Поскольку k нечётно и 2p чётно, сумма 2p + k нечётна. Но все слова в L имеют чётную длину, следовательно xy²z ∉ L.
  Накачанное слово: xy⁰z = a^(p−k) b^p
  Противоречие: Длина xy⁰z равна |a^(p−k) b^p| = 2p − k. Поскольку k чётно и 2p чётно, длина чётна — аргумент чётности здесь не работает напрямую. Используем другой подход. Рассмотрим количество символов a и b в словах из L ∩ a*b*. Докажем индукцией по дереву вывода, что для любого слова w ∈ L ∩ a*b* выполняется #a(w) ≥ #b(w). Базис: S → ε даёт ε (0 ≥ 0 ✓); S → A → aa даёт 2 ≥ 0 ✓; S → A → bb даёт 0 ≥ 2 ✗, но bb ∉ a*b* в смысле a⁺b⁺ — точнее bb = a⁰b², что формально принадлежит a*b*, и здесь #a < #b. Значит, нужно уточнить аргумент. Пересмотрим: выберем слово w = a^p b^p при p ≥ 2 и используем i = 0. Тогда xy⁰z = a^(p−k)b^p. Покажем, что это слово не в L, используя пересечение с регулярным языком. Если L регулярен, то L' = L ∩ a*b* тоже регулярен. Слова вида a^m b^n в L': из грамматики можно вывести a^m b^n ∈ L только если определённые соотношения между m и n выполняются. Однако этот случай требует более тонкого анализа — см. альтернативный подход ниже.

**Заключение:** Приведённый выше анализ по чётности покрывает случай нечётного k, но случай чётного k требует дополнительного аргумента. Применим метод замыкания (closure) для завершения доказательства.

### Теорема Майхилла-Нероуда
**Семейство слов:** (ab)^i для i \u2208 i >= 0

**Различающие контексты:**
| Пара | Контекст | В языке | Не в языке |
|------|---------|---------|------------|
| ['(ab)^i', '(ab)^j'] | a (ba)^{i-1} b  (i.e., context that completes (ab)^i into (ab)^{2i} ∈ L but (ab)^j concatenated with this context gives (ab)^j a(ba)^{i-1}b which has length 2j+2i and structure incompatible with balanced derivation) | (ab)^i · a(ba)^{i-1}b = (ab)^{2i} ∈ L, поскольку (ab)^n ∈ L для всех n (выводится из S → SaSb с S→ε для всех внутренних S) | (ab)^j · a(ba)^{i-1}b: слово длины 2(i+j), но структура не соответствует ни одному выводу из грамматики при j≠i, так как количество вложенных пар SaSb определяется однозначно |

**Аргумент:** Рассмотрим бесконечное семейство слов w_i = (ab)^i, i ≥ 0. Все слова (ab)^n принадлежат L, так как выводятся из S многократным применением правила S → SaSb с заменой всех промежуточных S на ε. Для любых i ≠ j рассмотрим контекст z = a(ba)^{i-1}b. Тогда w_i·z = (ab)^i · a(ba)^{i-1}b = (ab)^{2i} ∈ L. Однако w_j·z = (ab)^j · a(ba)^{i-1}b — слово длины 2(i+j), которое не принадлежит L при j ≠ i, поскольку грамматика порождает слова со строго определённой рекурсивной структурой вложенных пар SaSb, и конкатенация (ab)^j с суффиксом, рассчитанным на (ab)^i, нарушает эту структуру. Таким образом, семейство {(ab)^i | i ≥ 0} попарно различимо относительно ≡_L, и отношение Нероуда имеет бесконечный индекс.

**Заключение:** По теореме Майхилла-Нероуда, язык L не является регулярным, так как отношение эквивалентности Нероуда ≡_L имеет бесконечный индекс.

### Замыкание
**Метод:** intersection_with_regular
**Регулярный язык:** `a+b+` (Язык a⁺b⁺ описывается регулярным выражением aa*bb*, следовательно, является регулярным.)
**Результат пересечения:** {a^n b^n | n >= 1}
**Заключение:** Обозначим L = L(G). Рассмотрим пересечение L ∩ a⁺b⁺. Покажем, что L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Включение ⊇: из правила S → SaSb при многократном применении с S → ε получаем aⁿbⁿ ∈ L для всех n ≥ 0, а при n ≥ 1 эти слова лежат в a⁺b⁺. Включение ⊆: единственные слова из L, целиком состоящие из блока a⁺ и затем блока b⁺, — это именно aⁿbⁿ, поскольку правило A → aa даёт слово без b, правило A → bb даёт слово без a, правило A → bSb порождает слова, начинающиеся с b, а рекурсия S → SaSb при подстановке непустых S нарушает структуру a*b*. Таким образом, L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Язык a⁺b⁺ регулярен, класс REG замкнут относительно пересечения. Если бы L был регулярным, то L ∩ a⁺b⁺ тоже был бы регулярным. Но {aⁿbⁿ | n ≥ 1} — классический нерегулярный язык (доказывается леммой о накачке). Противоречие. Следовательно, L не является регулярным.

## Консолидированное доказательство
Докажем, что язык L, порождённый грамматикой S → SaSb | ε | A, A → bb | aa | bSb, не является регулярным.

**Метод:** замыкание регулярных языков относительно пересечения.

**Шаг 1.** Покажем, что L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}.

*Включение ⊇:* Слово aⁿbⁿ (n ≥ 1) выводится из грамматики следующим образом. Применяем правило S → SaSb, заменяя каждый раз левый S на ε:
  S ⇒ SaSb ⇒ aSb ⇒ aSaSbb ⇒ aaSbb ⇒ ... ⇒ aⁿbⁿ.
Таким образом, aⁿbⁿ ∈ L для всех n ≥ 0, и при n ≥ 1 имеем aⁿbⁿ ∈ a⁺b⁺.

*Включение ⊆:* Покажем структурной индукцией по дереву вывода, что если w ∈ L и w ∈ a*b*, то w = aⁿbⁿ для некоторого n ≥ 0.
- Базис: S → ε даёт ε = a⁰b⁰ ✓.
- S → A → aa: слово aa = a²b⁰, но aa ∉ a⁺b⁺ (нет символов b после a), поэтому aa ∉ a⁺b⁺. Формально aa ∈ a*b* (как a²b⁰), но aa ∉ a⁺b⁺. Для пересечения с a*b* заметим, что a² ≠ aⁿbⁿ при n ≥ 1. Однако a² = a²b⁰ ∈ L ∩ a*b*, и это соответствует n = 0 в расширенном смысле (если рассматривать a*b*, то a² не имеет вида aⁿbⁿ). Уточним: рассмотрим пересечение L ∩ a⁺b⁺, где a⁺b⁺ требует хотя бы один символ a и хотя бы один символ b. Тогда:
  - S → A → aa даёт aa ∉ a⁺b⁺ (нет b).
  - S → A → bb даёт bb ∉ a⁺b⁺ (нет a).
  - S → A → bSb даёт слово, начинающееся с b, поэтому bSb ∉ a⁺b⁺.
  - S → SaSb: если S₁ порождает u ∈ a*b* и S₂ порождает v ∈ a*b*, то результат uavb ∈ a*b* только если u ∈ a* (т.е. u не содержит b) и v ∈ a*b* с vb ∈ b* (т.е. v ∈ b*). По индукции u = aⁱbⁱ ∈ a* означает i = 0, т.е. u = ε. Аналогично v = aʲbʲ ∈ b* означает j = 0, т.е. v = ε. Тогда результат = ε · a · ε · b = ab. Рекурсивно применяя этот аргумент, единственные слова из L ∩ a⁺b⁺ — это aⁿbⁿ при n ≥ 1.

Итого: L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}.

**Шаг 2.** Язык a⁺b⁺ регулярен (задаётся регулярным выражением aa*bb*).

**Шаг 3.** Класс регулярных языков замкнут относительно пересечения. Если бы L был регулярным, то L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1} тоже был бы регулярным.

**Шаг 4.** Язык {aⁿbⁿ | n ≥ 1} не является регулярным (классический результат, доказываемый леммой о накачке: для слова aᵖbᵖ любое разбиение xyz с |xy| ≤ p даёт y = aᵏ, k ≥ 1, и xy²z = aᵖ⁺ᵏbᵖ ∉ {aⁿbⁿ}).

**Вывод.** Получено противоречие. Следовательно, язык L не является регулярным. ∎

## Подсказки и наблюдения
- Установлено: L ∩ a⁺b⁺ = {aⁿbⁿ | n ≥ 1}. Это ключевой факт для доказательства.
- Включение ⊇ тривиально: aⁿbⁿ выводится через S → SaSb с S₁ → ε на каждом шаге.
- Включение ⊆ доказывается структурной индукцией: правило S → SaSb при подстановке слов из a*b* вынуждает оба подвывода S давать ε (иначе нарушается структура a*b*).
- Рекомендация для экзамена: наиболее чистое и короткое доказательство — через замыкание (пересечение с регулярным языком a⁺b⁺). Это стандартный приём.
- Альтернатива: можно применить лемму о накачке напрямую к L ∩ a*b*, рассматривая слово aᵖbᵖ уже в пересечённом языке {aⁿbⁿ}, где доказательство стандартно.
- Наблюдение о структуре: все слова в L имеют чётную длину (доказывается индукцией по дереву вывода). Это полезное вспомогательное свойство, но само по себе недостаточно для доказательства нерегулярности.
- Грамматика содержит вложенную рекурсию S → SaSb и A → bSb, что делает её существенно контекстно-свободной (не приводимой к праволинейной или леволинейной форме).
- Примеры слов из L: ε, aa, bb, ab, aabb, abbb, aaab, baab, bbab, bbbb, aaabbb, ababab, ...
