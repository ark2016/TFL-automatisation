# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: participants are expected to be respectful, constructive, and professional in all project spaces (issues, pull requests, discussions). Disagreements about technical decisions are welcome; personal attacks are not.

## Reporting

If you encounter behavior that violates the Covenant, please open a private message to the repository owner via the email listed on the GitHub profile, or use GitHub's [abuse report form](https://github.com/contact/report-abuse).

The full Covenant text is available at the link above and is the authoritative policy for this project.
