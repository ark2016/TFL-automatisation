# Универсальный алгоритм вычисления обратного гомоморфизма для регулярных языков

## Теоретическая основа

### Определение задачи

Дан регулярный язык $L \subseteq \Sigma^*$ и гомоморфизм $h: \Delta \to \Sigma^*$. Требуется построить автомат, распознающий язык:

$$h^{-1}(L) = \{w \in \Delta^* \mid h(w) \in L\}$$

**Теорема (Замкнутость):** Класс регулярных языков замкнут относительно операции обратного гомоморфизма. То есть если $L$ регулярен, то $h^{-1}(L)$ также регулярен.

### Классификация гомоморфизмов

1. **Нестирающий гомоморфизм**: $h: \Delta \to \Sigma^+$ (все образы непустые)
2. **Стирающий гомоморфизм**: $h: \Delta \to \Sigma^*$ (некоторые образы могут быть $\varepsilon$)

Алгоритм работает для обоих типов с минимальными модификациями.

---

## Полный алгоритм

### Входные данные
- Регулярное выражение или ДКА для языка $L$
- Гомоморфизм $h: \Delta \to \Sigma^*$, заданный таблицей $\{a \mapsto h(a) \mid a \in \Delta\}$

### Выходные данные
- Минимальный ДКА для языка $h^{-1}(L)$

---

## Этап 1: Построение тотального ДКА для исходного языка $L$

### Шаг 1.1: Получение ДКА

**Если дано регулярное выражение:**

1. **Thompson construction**: Построить $\varepsilon$-NFA из регулярного выражения
   - Базовые случаи: пустой язык, $\varepsilon$, одиночный символ
   - Индуктивные случаи: конкатенация, объединение, звезда Клини

2. **Subset construction с $\varepsilon$-замыканием**: Преобразовать $\varepsilon$-NFA в ДКА
   - Для каждого подмножества состояний $S$ вычислять $\varepsilon\text{-closure}(S)$
   - Новые состояния ДКА — это непустые подмножества состояний NFA
   - Переходы: $\delta_{DFA}(S, a) = \varepsilon\text{-closure}\bigl(\bigcup_{q \in S} \delta_{NFA}(q, a)\bigr)$

**Если уже дан ДКА:** Использовать его напрямую.

### Шаг 1.2: Приведение к тотальному ДКА

Классический ДКА требует, чтобы функция переходов $\delta: Q \times \Sigma \to Q$ была **тотальной** (определена для всех пар).

**Процедура:**
1. Добавить специальное **мертвое состояние** (sink state) $q_{\text{sink}} \notin F$
2. Для каждой пары $(q, a) \in Q \times \Sigma$:
   - Если переход $\delta(q, a)$ не определен, установить $\delta(q, a) = q_{\text{sink}}$
3. Добавить самопетли: $\delta(q_{\text{sink}}, a) = q_{\text{sink}}$ для всех $a \in \Sigma$

**Результат:** Тотальный ДКА $M = (Q, \Sigma, \delta, q_0, F)$ для языка $L$.

---

## Этап 2: Построение ДКА для $h^{-1}(L)$

### Основная идея

Новый автомат будет иметь те же состояния, но работать над алфавитом $\Delta$. При чтении символа $a \in \Delta$ автомат должен имитировать обработку всей строки $h(a)$ в исходном автомате $M$.

### Конструкция

Построить новый ДКА $M' = (Q, \Delta, \delta', q_0, F)$, где:

- **Множество состояний**: $Q$ (то же, что у $M$)
- **Алфавит**: $\Delta$ (алфавит гомоморфизма)
- **Начальное состояние**: $q_0$ (то же)
- **Финальные состояния**: $F$ (те же)
- **Функция переходов**: $\delta'$ определяется по правилу:

$$\delta'(q, a) = \hat{\delta}(q, h(a))$$

где $\hat{\delta}: Q \times \Sigma^* \to Q$ — **расширенная функция переходов**, определенная индуктивно:
- $\hat{\delta}(q, \varepsilon) = q$
- $\hat{\delta}(q, wa) = \delta\bigl(\hat{\delta}(q, w), a\bigr)$ для $w \in \Sigma^*, a \in \Sigma$

### Алгоритм вычисления $\delta'(q, a)$

```
Для каждого q ∈ Q:
    Для каждого a ∈ Δ:
        current_state := q
        word := h(a)  // образ символа (строка из Σ*)
        
        // Последовательно обрабатываем каждый символ в word
        Для каждого символа c в word:
            current_state := δ(current_state, c)
            // Поскольку δ тотальна, этот переход всегда существует
        
        δ'(q, a) := current_state
```

**Важно:** Поскольку $M$ тотален, цепочка переходов гарантированно завершится (возможно, в $q_{\text{sink}}$).

### Частный случай: стирающий гомоморфизм

Если для некоторого $a \in \Delta$ выполнено $h(a) = \varepsilon$, то:

$$\delta'(q, a) = \hat{\delta}(q, \varepsilon) = q$$

То есть автоматически получаются **самопетли** на всех состояниях по таким символам. Никакой дополнительной обработки не требуется — формула $\delta'(q, a) = \hat{\delta}(q, h(a))$ универсальна.

## Этап 3: Оптимизация результата

### Шаг 3.1: Удаление недостижимых состояний

Выполнить **обход в ширину** (BFS) из начального состояния $q_0$:

```
reachable := {q₀}
queue := [q₀]

while queue не пуста:
    q := queue.pop()
    для каждого a ∈ Δ:
        p := δ'(q, a)
        если p ∉ reachable:
            reachable := reachable ∪ {p}
            queue.push(p)

Q' := reachable
```

Удалить все состояния не из $Q'$ и связанные с ними переходы.

### Шаг 3.2: Минимизация ДКА

Применить **алгоритм Хопкрофта** для минимизации:

1. **Начальное разбиение**: $\pi = \{F, Q \setminus F\}$ (финальные и нефинальные)

2. **Итеративное уточнение**: Пока разбиение изменяется:
   - Для каждого блока $B \in \pi$ и символа $a \in \Delta$:
     - Разделить блоки, состояния которых переходят в разные блоки по $a$

3. **Построение минимального автомата**:
   - Новые состояния — блоки разбиения
   - Переходы между блоками

**Сложность**: $O(n \log n)$, где $n = |Q|$.

## Корректность алгоритма

### Теорема
Для всякого слова $w \in \Delta^*$ справедливо:

$$w \in L(M') \Leftrightarrow h(w) \in L(M)$$

### Доказательство

**Направление ($\Rightarrow$):** Пусть $w = a_1 a_2 \dots a_n \in L(M')$.

По определению $\delta'$:
$$\delta'(q_0, w) = \delta'(\delta'(\dots \delta'(q_0, a_1), \dots), a_n) \in F$$

Используя определение $\delta'(q, a) = \hat{\delta}(q, h(a))$:
$$\hat{\delta}(q_0, h(a_1) \cdot h(a_2) \cdot \ldots \cdot h(a_n)) = \hat{\delta}(q_0, h(w)) \in F$$

Следовательно, $h(w) \in L(M)$.

**Направление ($\Leftarrow$):** Аналогично, используя свойство гомоморфизма $h(a_1 a_2 \dots a_n) = h(a_1)h(a_2)\dots h(a_n)$.

## Сложность алгоритма

| Этап | Сложность |
|------|-----------|
| Thompson construction | $O(m)$, где $m$ — длина регулярного выражения |
| Subset construction | $O(2^n \cdot \|\Sigma\|)$ худший случай, где $n$ — число состояний NFA |
| Приведение к тотальному ДКА | $O(\|Q\| \cdot \|\Sigma\|)$ |
| Построение переходов для $h^{-1}(L)$ | $O(\|Q\| \cdot \|\Delta\| \cdot \max_a \|h(a)\|)$ |
| Минимизация (Хопкрофт) | $O(\|Q\| \log \|Q\| \cdot \|\Delta\|)$ |

**Общая сложность**: Экспоненциальная от размера регулярного выражения в худшем случае, но полиномиальная от размера входного ДКА.

---

## Важные свойства и ограничения

### Свойства прообраза

1. $h(h^{-1}(L)) \subseteq L$ (не всегда равенство!)
2. $L \subseteq h^{-1}(h(L))$
3. Если $h$ **инъективен**, то $h^{-1}(h(L)) = L$

### Композиции гомоморфизмов

$$(h_2 \circ h_1)^{-1}(L) = h_1^{-1}(h_2^{-1}(L))$$

Это позволяет разбивать сложные преобразования на простые.

### Применения техники

1. **Доказательство нерегулярности**: Переход к более простому языку через подходящий $h$
2. **Доказательство неконтекстной свободы**: Редукция к языку типа $\{a^n b^n c^n\}$
3. **Токенизация текста**: BPE-токенизация как обратный гомоморфизм (см. arXiv:2412.03160)
4. **Асинхронная конкатенация**: Доказательство замкнутости КС-языков относительно shuffle с регулярным

## Практический пример применения

### Задача
Построить $h^{-1}(L)$, где:
- $L = ((aba)^*bb \mid aa)^*$
- $h(a) = baa$, $h(b) = aaa$, $h(c) = a$, $h(d) = ab$

### Решение пошагово

**Шаг 1:** Построить ДКА для $L = ((aba)^*bb \mid aa)^*$

Применяем Thompson construction → Subset construction → получаем ДКА с, например, 6 состояниями. Добавляем sink state → 7 состояний.

**Шаг 2:** Применяем конструкцию для $h^{-1}(L)$

Новый алфавит: $\Delta = \{a, b, c, d\}$

Для каждого состояния $q$ и каждого символа из $\Delta$ вычисляем:
- $\delta'(q, a) = \hat{\delta}(q, \text{"baa"})$ — прогоняем через исходный ДКА последовательность $b \to a \to a$
- $\delta'(q, b) = \hat{\delta}(q, \text{"aaa"})$ — прогоняем $a \to a \to a$
- $\delta'(q, c) = \hat{\delta}(q, \text{"a"})$ — прогоняем $a$
- $\delta'(q, d) = \hat{\delta}(q, \text{"ab"})$ — прогоняем $a \to b$

**Шаг 3:** Минимизация

После удаления недостижимых состояний и минимизации получаем компактный ДКА для $h^{-1}(L)$.

**Проверка корректности:**
Для любого слова $w \in \Delta^*$ проверяем:
- $w \in h^{-1}(L)$ ⟺ $h(w) \in L$

Например:
- $w = "ac"$ → $h(w) = "baa" + "a" = "baaa"$
- Проверяем, принимает ли исходный ДКА слово "baaa"

## Расширения и обобщения

### Для контекстно-свободных языков

**Теорема:** Класс КС-языков также замкнут относительно обратных гомоморфизмов.

**Алгоритм:**
1. Вместо ДКА используем **магазинный автомат** (PDA)
2. Конструкция аналогична: $\delta'(q, Z, a) = \hat{\delta}(q, Z, h(a))$
3. Сложность возрастает, но принцип тот же

### Для детерминированных КС-языков (ДКСЯ)

ДКСЯ также замкнуты относительно обратных гомоморфизмов, но конструкция требует детерминированного магазинного автомата (DPDA).

## Типичные ошибки и как их избежать

### Ошибка 1: Забыть сделать ДКА тотальным
**Проблема:** Если $\delta(q, a)$ не определена, то вычисление $\hat{\delta}(q, h(b))$ может «зависнуть».

**Решение:** Всегда добавляйте sink state перед этапом 2.

### Ошибка 2: Перепутать $h(L)$ и $h^{-1}(L)$
**Проблема:** Прямой гомоморфизм $h(L) = \{h(w) \mid w \in L\}$ требует другого алгоритма!

**Решение:** В обратном гомоморфизме мы **не декодируем** строки обратно, а строим автомат по формуле через образы символов.

### Ошибка 3: Считать, что нужен «код»
**Проблема:** Думать, что множество $\{h(a) \mid a \in \Delta\}$ должно быть префиксным/суффиксным кодом.

**Решение:** Для $h^{-1}(L)$ свойство кода НЕ требуется. Алгоритм работает для любого гомоморфизма.

### Ошибка 4: Неправильная обработка $\varepsilon$
**Проблема:** При стирающем гомоморфизме забыть, что $\hat{\delta}(q, \varepsilon) = q$.

**Решение:** Формула $\delta'(q, a) = \hat{\delta}(q, h(a))$ автоматически обрабатывает этот случай.

## Практические соображения реализации

### Оптимизация для больших алфавитов

Если $|\Delta|$ очень велик (например, все UTF-8 символы):
1. Используйте **символьные автоматы** (Symbolic Automata), где переходы помечены предикатами, а не отдельными символами
2. Группируйте символы с одинаковыми образами

### Кэширование вычислений $\hat{\delta}$

Если образы гомоморфизма длинные:
```python
cache = {}

def extended_delta(q, word):
    if (q, word) in cache:
        return cache[(q, word)]
    
    current = q
    for char in word:
        current = delta(current, char)
    
    cache[(q, word)] = current
    return current
```

### Ленивые вычисления

Не строить весь автомат сразу, а вычислять переходы «на лету» при необходимости (полезно для очень больших автоматов).

### Ключевые выводы:

1. **Универсальность**: Работает для любого гомоморфизма (нестирающего и стирающего)
